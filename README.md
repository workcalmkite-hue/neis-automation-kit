# 나이스 자동화 키트 (교사용)

구글 캘린더에 출결을 적어두면 **나이스에 자동으로 옮겨 적어주는** 도구입니다.
본인 조퇴·외출·지각 같은 **복무 신청**과 **출장·41조 연수 상신**도 함께 들어 있습니다.

담임 한 달치 출결을 손으로 옮기는 데 걸리던 시간이 몇 분으로 줄어듭니다.

---

## ⚠️ 먼저 읽어주세요

- **나이스는 정부 시스템입니다.** 이 도구는 브라우저를 자동으로 조작하는 방식이고,
  자동화 프로그램 사용이 학교·교육청 지침에 어긋날 소지가 있습니다.
  **쓰기 전에 소속 학교나 교육청에 한 번 확인해 보시고, 사용은 본인 책임입니다.**
- **본인 계정으로 본인 업무만** 하세요. 남의 인증서·계정으로 돌리지 마세요.
- 이 도구는 **입력을 대신할 뿐 판단하지 않습니다.** 돌린 뒤에는 나이스 화면에서
  실제로 맞게 들어갔는지 **눈으로 확인**하세요.
- 학생 이름·출결 사유는 **내 PC와 내 구글 계정 안에만** 있습니다.
  어디로도 전송되지 않습니다. 그래도 **캡처·로그 파일을 남에게 주지 마세요.**

---

## 무엇이 들어 있나요

| | 하는 일 | 실행 방법 |
|---|---|---|
| **학생 출결 입력** | 구글 캘린더 → 나이스 「일일출결관리(담임용)」 자동 입력 | `python main.py` |
| **출결 검증** | 캘린더와 나이스가 어긋난 곳 찾기 (읽기만, 아무것도 안 고침) | `python verify_attendance.py 2026-09-01 2026-09-30` |
| **본인 복무** | 조퇴·외출·지각 자동 신청 + 상신 | `python main_bokmu.py --type 조퇴 ...` |
| **출장 · 41조 연수** | Claude Code가 직접 나이스 화면을 조작 | Claude Code에 `/나이스출장` |
| **MCP 서버** | 캘린더 만들기·출결 넣기를 말로 시키기 | 폴더를 열면 자동 연결 |

Claude Code로 쓰면 명령어를 외울 필요 없이 **"9월 출결 넣어줘"** 처럼 말하면 됩니다.

## 매일 쓰는 법

### 1) 캘린더에 적기

구글 캘린더에서 **분류 이름과 같은 캘린더**를 골라, 제목을 이렇게 적습니다.

```
1 홍길동 출석인정결석
2 김철수 질병조퇴 (2교시~)
7 박지우 질병지각 (~2교시)
```

- `번호` `이름` 순서로, **번호 뒤에 "번"을 붙이지 않습니다** (`14번 김하늘` ❌ / `14 김하늘` ⭕)
- 교시는 괄호 안에. **조퇴는 `5교시~`**(그 교시부터 없음), **지각은 `~2교시`**(그 교시까지 없었음)
- 결석은 **종일 일정**으로. 여러 날이면 기간으로 (구글 캘린더는 종료일이 하루 뒤로 들어갑니다)

자세한 규칙과 예시는 [docs/03_캘린더-입력규칙.md](docs/03_캘린더-입력규칙.md)에 있습니다.

> **캘린더 9개는 설정 마법사가 자동으로 만들어 줍니다.**
> 따로 만들고 싶으시면 [docs/05_MCP-연결.md](docs/05_MCP-연결.md)(말로 시키기)나
> [docs/03](docs/03_캘린더-입력규칙.md)의 앱스스크립트 방법을 쓰세요.
> ⚠️ 구글 공식 캘린더 MCP에는 **캘린더를 만드는 기능이 없습니다** — 그래서 이 저장소가 `mcp_server.py`로 채웁니다.

### 2) 나이스에 옮기기

VS Code에서 Claude Code를 켜고 이렇게 말하면 됩니다.

```
/나이스출결
```

또는 터미널에서 직접:

```powershell
.\.venv\Scripts\python.exe main.py --dry-run   # 무엇을 넣을지 목록만 보기 (나이스 안 엶)
.\.venv\Scripts\python.exe main.py              # 이번 달 1일 ~ 오늘
.\.venv\Scripts\python.exe main.py 2026-09-10   # 그 날짜부터 오늘까지
```

크롬이 열리고 → 인증서 로그인 → 출결관리 화면으로 이동 → 날짜별로 입력 → 저장까지 알아서 합니다.
**중간에 크롬 창을 건드리지 말고 그냥 두세요.**

## 내 정보는 어디에 저장되나요

| 무엇 | 어디에 | 저장소에 올라가나요 |
|---|---|---|
| 학년·반·인증서 이름·캘린더 ID | `%LOCALAPPDATA%\neis-automation\teacher_config.json` | ❌ (저장소 밖) |
| 인증서 비밀번호 | Windows **자격 증명 관리자** (keyring) | ❌ (파일로 존재하지 않음) |
| 구글 접근 토큰 | `%LOCALAPPDATA%\neis-automation\token.json` | ❌ (저장소 밖) |
| 구글 OAuth 열쇠 | `oauth_client.json` | ❌ (`.gitignore`로 차단) |
| 학생 이름·출결 | 내 구글 캘린더 + 나이스 | ❌ (저장소에 파일로 만들지 않음) |

**이 저장소에는 학생 정보도, 비밀번호도, 학교 이름도 들어 있지 않습니다.**
스크린샷(`*.png`)·로그(`*.log`)·엑셀(`*.csv`, `*.xlsx`)은 `.gitignore`로 통째로 막아뒀습니다 —
디버깅하다 만든 파일에 학생 이름이 찍혀 있어도 실수로 올라가지 않습니다.

## 지역·학교가 다르면

- **나이스 주소**는 시도교육청마다 다릅니다. 설정 마법사가 물어보니, 브라우저로
  본인 지역 나이스에 접속해서 **주소창을 그대로 붙여넣으면** 됩니다.
  (서울은 `https://sen.neis.go.kr/jsp/main.jsp`)
- **결재선**은 학교마다 다릅니다. 나이스에 개인결재선을 미리 저장해 두고,
  그 **프리셋 이름**을 설정에 적으면 됩니다.
- **학교 밖 접속(EVPN 등)은 들어 있지 않습니다.** 시도교육청마다 방식이 달라 뺐습니다.
  학교 안에서, 또는 VPN을 직접 연결한 상태에서 실행하세요.
