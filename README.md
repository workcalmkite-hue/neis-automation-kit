# 교사용 나이스·에듀파인 자동화 키트

**클로드(Claude)에게 말로 시키면 나이스·에듀파인 업무를 대신 해 주는 도구**입니다.

구글 캘린더에 출결을 적어두면 나이스에 옮겨 적어 주고, 조퇴·출장 같은 복무 신청도 대신 올려 줍니다.
에듀파인 지출품의와 물품 검수도 함께 들어 있습니다.

담임 한 달치 출결을 손으로 옮기는 데 걸리던 시간이 몇 분으로 줄어듭니다.

---

## ⚠️ 먼저 읽어주세요

- **나이스·에듀파인은 정부 시스템입니다.** 이 도구는 브라우저를 자동으로 조작하는 방식이고,
  자동화 프로그램 사용이 학교·교육청 지침에 어긋날 소지가 있습니다.
  **쓰기 전에 소속 학교나 교육청에 한 번 확인해 보시고, 사용은 본인 책임입니다.**
- **본인 계정으로 본인 업무만** 하세요. 남의 인증서·계정으로 돌리지 마세요.
- 이 도구는 **입력을 대신할 뿐 판단하지 않습니다.** 돌린 뒤에는 화면에서
  실제로 맞게 들어갔는지 **눈으로 확인**하세요.
- 학생 이름·출결 사유는 **내 PC와 내 구글 계정 안에만** 있습니다.
  어디로도 전송되지 않습니다. 그래도 **캡처·로그 파일을 남에게 주지 마세요.**

## 무엇이 들어 있나요

| | 하는 일 |
|---|---|
| **학생 출결 입력** | 구글 캘린더에 적어둔 출결 → 나이스 「일일출결관리(담임용)」 자동 입력 |
| **출결 검증** | 캘린더와 나이스를 날짜·학생별로 대조해 **일치/빠짐/분류다름/교시다름**을 표로 출력 (읽기만, 아무것도 안 고침) |
| **본인 복무** | 조퇴·외출·지각 자동 신청 + 상신 |
| **출장 · 41조 연수** | 인증서로 로그인해 둔 크롬에 붙어 출장·연수 상신 |
| **에듀파인 지출품의** | 쇼핑몰 링크에서 품명·가격을 읽어 품의 화면을 채우고 저장 |
| **에듀파인 물품 검수** | 검사검수요청목록에서 밀린 건을 확인하고 등록 |

명령어를 외울 필요는 없습니다. **"9월 출결 넣어줘"** 처럼 말하면 됩니다.

## 설치 — 세 가지만 깔면 됩니다

깔 것은 셋뿐이고, 나머지(파이썬·라이브러리)는 **클로드가 알아서 깝니다.**

1. **구글 크롬** — https://google.com/chrome (엣지·웨일로는 안 됩니다)
2. **Git** — https://git-scm.com/download/win (전부 그대로 두고 [Next] 만 누르세요)
3. **클로드 데스크톱 앱** — https://claude.ai/download (설치 후 로그인 · **유료 요금제라야 됩니다**)

그다음,

4. **바탕화면에 폴더를 하나 만들고 이름을 `obsidian` 으로** 붙입니다 (빈 폴더로 두세요)
5. 클로드 앱을 켜고 위쪽 **[Code] 탭 → Local → [Select folder]** 로 그 폴더를 고릅니다
6. 아래 입력칸에 **이 문장을 통째로 붙여넣고 엔터**를 칩니다

```
https://github.com/workcalmkite-hue/neis-automation-kit 를 지금 열려 있는 이 폴더에 받아줘. 폴더가 비어 있지 않아서 git clone 이 안 되면 git init → git remote add origin → git pull origin main 으로 받아줘. 다 받으면 시작하기.md 를 읽고 거기 적힌 대로 나를 안내해줘.
```

받고 나면 **클로드 앱을 완전히 껐다 다시 켜세요.** (권한 설정은 켤 때 한 번만 읽힙니다)
그다음부터는 클로드가 하나씩 물어봅니다. 대답만 하시면 됩니다.

> 눈으로 보며 따라가고 싶으시면 함께 드린 **「처음 세팅 설명서」 HTML** 을 더블클릭해서 크롬으로 여세요.

## 매일 쓰는 법

### 1) 캘린더에 적기

구글 캘린더에서 **분류 이름과 같은 캘린더**를 골라, 제목을 이렇게 적습니다.

```
1 홍길동 출석인정결석
2 김철수 질병조퇴 (2교시~)
7 박지우 질병지각 (~2교시)
```

- `번호` `이름` 순서로, **번호 뒤에 "번"을 붙이지 않습니다** (`14번 김하늘` ❌ / `14 김하늘` ⭕)
- 교시는 괄호 안에. **조퇴는 `5교시~`**(그 교시부터 없음), **지각은 `~2교시`**(그 교시까지 없었음)
- 결석은 **종일 일정**으로. 여러 날이면 기간으로 (구글 캘린더는 종료일이 하루 뒤로 들어갑니다)

자세한 규칙과 예시는 [docs/03_캘린더-입력규칙.md](docs/03_캘린더-입력규칙.md)에 있습니다.

> **캘린더 9개는 설정 마법사가 자동으로 만들어 줍니다.**
> ⚠️ 구글 공식 캘린더 MCP에는 **캘린더를 만드는 기능이 없습니다** — 그래서 이 저장소가 `mcp_server.py`로 채웁니다.

### 2) 나이스에 옮기기

클로드 앱에서 그 폴더를 연 채로 이렇게 말하면 됩니다.

```
9월 출결 넣어줘
```

크롬이 열리고 → 인증서 로그인 → 출결관리 화면으로 이동 → 날짜별로 입력 → 저장까지 알아서 합니다.
**중간에 크롬 창을 건드리지 말고 그냥 두세요.**

검은 창에서 직접 돌리실 때는,

```powershell
.\.venv\Scripts\python.exe main.py --dry-run   # 무엇을 넣을지 목록만 보기 (나이스 안 엶)
.\.venv\Scripts\python.exe main.py              # 이번 달 1일 ~ 오늘
.\.venv\Scripts\python.exe main.py 2026-09-10   # 그 날짜부터 오늘까지
```

## 내 정보는 어디에 저장되나요

| 무엇 | 어디에 | 저장소에 올라가나요 |
|---|---|---|
| 학년·반·인증서 이름·캘린더 ID | `%LOCALAPPDATA%\neis-automation\teacher_config.json` | ❌ (저장소 밖) |
| 인증서 비밀번호 | Windows **자격 증명 관리자** (keyring) | ❌ (파일로 존재하지 않음) |
| 구글 접근 토큰 | `%LOCALAPPDATA%\neis-automation\token.json` | ❌ (저장소 밖) |
| 구글 OAuth 열쇠 | `oauth_client.json` | ❌ (`.gitignore`로 차단) |
| 학생 이름·출결 | 내 구글 캘린더 + 나이스 | ❌ (저장소에 파일로 만들지 않음) |

**이 저장소에는 학생 정보도, 비밀번호도, 다른 학교 이름도 들어 있지 않습니다.**
스크린샷(`*.png`)·로그(`*.log`)·엑셀(`*.csv`, `*.xlsx`)은 `.gitignore`로 통째로 막아뒀습니다 —
디버깅하다 만든 파일에 학생 이름이 찍혀 있어도 실수로 올라가지 않습니다.

## 지역·학교가 다르면

- **나이스 주소**는 시도교육청마다 다릅니다. 설정 마법사가 물어보니, 브라우저로
  본인 지역 나이스에 접속해서 **주소창을 그대로 붙여넣으면** 됩니다.
  (서울은 `https://sen.neis.go.kr/jsp/main.jsp`)
- **결재선**은 학교마다 다릅니다. 나이스에 개인결재선을 미리 저장해 두고,
  그 **프리셋 이름**을 설정에 적으면 됩니다.
- **학교 밖 접속(EVPN 등)은 들어 있지 않습니다.** 시도교육청마다 방식이 달라 뺐습니다.
  학교 안에서, 또는 VPN을 직접 연결한 상태에서 실행하세요.
