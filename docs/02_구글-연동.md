# 2. 구글 캘린더 연동하기

이 도구는 **내 구글 캘린더를 읽어서** 나이스에 옮겨 적습니다.
그래서 "이 프로그램이 내 캘린더를 봐도 된다"는 **열쇠**를 한 번 만들어야 합니다.

> **왜 제가 직접 만들어야 하나요?**
> 만들어진 열쇠를 저장소에 같이 넣어두면 아무나 쓸 수 있게 되고, 구글도 그걸 막습니다.
> 그래서 각자 본인 것을 만듭니다. **무료이고, 5~10분이면 됩니다.**

---

## 1) 구글 클라우드에서 프로젝트 만들기

1. https://console.cloud.google.com/ 접속 (출결 캘린더를 쓸 **본인 구글 계정**으로 로그인)
2. 처음이면 약관 동의 화면이 뜹니다 — 동의합니다
3. 상단 왼쪽 **프로젝트 선택** 드롭다운 → 창 오른쪽 위 **[새 프로젝트]**
4. 이름은 **영어·숫자·하이픈으로** (예: `neis-attendance`) → **[만들기]**

   ⛔ **한글 이름은 안 됩니다.** `나이스출결`이라고 치면 «이름에 잘못된 문자가 포함되어 있습니다»가 뜹니다
5. 만들어져도 **화면 위 프로젝트는 그대로입니다.** 오른쪽 위 알림창의 **[프로젝트 선택]** 을 눌러
   방금 만든 프로젝트로 바꿔 주세요 (여기서 안 바꾸면 다음 단계가 엉뚱한 프로젝트에 설정됩니다)

---

## 2) 사용할 API 켜기

1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**
2. `Google Calendar API` 검색 → 클릭 → **[사용]**
3. 다시 라이브러리로 돌아가 `Google Sheets API` 검색 → **[사용]**
   - 휴업일 시트를 안 쓸 거면 건너뛰어도 됩니다

---

## 3) 동의 화면 설정

> 구글이 이 화면을 **「Google 인증 플랫폼」** 으로 바꿨습니다 (2026-09 확인). 아래는 새 화면 기준입니다.

1. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면** → **[시작하기]**
2. **① 앱 정보** — 앱 이름 아무거나 (여기는 한글 됩니다. 예: `나이스출결`), 사용자 지원 이메일은 내 계정 → [다음]
3. **② 대상** — **외부(External)** → [다음]
4. **③ 연락처 정보** — 내 이메일 → [다음]
5. **④ 완료** — 「Google API 서비스: 사용자 데이터 정책」 **체크** → **[만들기]**

   (예전에 있던 **범위(Scopes)** 화면은 없어졌습니다. 안 나와도 정상입니다)
6. 만들어지면 왼쪽 메뉴 **[대상]** → 아래로 내려 **테스트 사용자 [+ Add users]**
   → 내 구글 이메일 입력 → **[저장]**

   ⭐ 이 단계를 빼먹으면 나중에 `앱이 차단됨` 오류가 납니다.
   ⭐ 이메일을 치면 자동완성 목록이 떠서 [저장] 첫 클릭이 먹지 않을 수 있습니다 — 한 번 더 누르세요.

---

## 3-1) ⭐ 앱 게시 — 안 하면 7일마다 다시 로그인해야 합니다

방금 만든 앱은 **「테스트 중」** 상태입니다. 이 상태에서는 구글이 **7일 뒤에 열쇠를 만료**시켜서,
일주일에 한 번씩 «구글 로그인 창»이 다시 뜹니다 (2026-08 실측 — 프로덕션으로 바꾸고 나서는 18일 넘게 그대로 살아 있었습니다).

1. 왼쪽 메뉴 **[대상]**
2. 게시 상태 아래 **[앱 게시]** → 확인

- 심사(verification)를 받지 않아도 게시됩니다. 대신 로그인할 때 «Google에서 확인하지 않은 앱» 안내가 계속 뜨는데,
  **[계속]** 을 누르면 그대로 쓸 수 있습니다 (내가 만든 앱을 나 혼자 쓰는 것이라 괜찮습니다)
- 테스트 사용자 목록은 게시 뒤에는 필요 없습니다

---

## 4) 열쇠(OAuth 클라이언트) 만들기

1. 왼쪽 메뉴 **[클라이언트]** → **[+ 클라이언트 만들기]**
   (예전 경로인 **API 및 서비스 → 사용자 인증 정보**로 가도 같은 화면이 나옵니다)
2. 애플리케이션 유형: ⭐ **데스크톱 앱** (웹 애플리케이션 아님!)
3. 이름은 그냥 두고 → **[만들기]**
4. 팝업에 **클라이언트 ID**와 **클라이언트 보안 비밀번호**가 나옵니다 — 이 창을 닫지 마세요
   (각 줄 오른쪽 **복사 아이콘**을 누르면 그대로 복사됩니다)

---

## 5) `oauth_client.json` 만들기

1. VS Code 왼쪽 파일 목록에서 **`oauth_client.example.json`** 을 찾습니다
2. 파일 이름 위에서 **마우스 오른쪽 → 복사**, 다시 빈 곳에서 **오른쪽 → 붙여넣기**
3. 생긴 파일 이름을 **`oauth_client.json`** 으로 바꿉니다 (오른쪽 → 이름 바꾸기)
4. 파일을 열어 아래처럼 값만 바꿔 넣고 **`Ctrl+S`로 저장**합니다

```json
{
  "client_id": "1234567890-abcdefg.apps.googleusercontent.com",
  "client_secret": "GOCSPX-xxxxxxxxxxxxxxxx"
}
```

- 4번에서 본 값을 그대로 복사해 넣으면 됩니다
- `_설명` 줄은 지워도 되고 남겨도 됩니다
- ⭐ **탭 이름에 ● 이 남아 있으면 저장이 안 된 것입니다.** `Ctrl+S`를 다시 누르세요

> 🔒 이 파일은 `.gitignore`에 걸려 있어 **깃허브에 절대 올라가지 않습니다.**
> 확인하고 싶으면 터미널에서 `git status` 를 쳐보세요 — 목록에 안 나오면 정상입니다.

---

## 6) 최초 설정 실행

VS Code 터미널에서:

```powershell
.\.venv\Scripts\python.exe setup_wizard.py
```

차례로 물어봅니다. 모르면 그냥 Enter를 눌러도 되는 항목이 대부분입니다.

| 물어보는 것 | 뭘 넣나요 |
|---|---|
| 나이스 주소 | 서울이면 그냥 Enter. 다른 지역이면 브라우저 주소창을 복사해 붙여넣기 |
| 학년 / 반 | 담임 학급 (예: `1`, `7`) |
| 인증서 이름 | [01번 문서 A-3](01_처음-준비.md)에서 메모해 둔 값. 나이스 인증서 창의 **「사용자」 칸 글자 그대로** (예: `851홍길동005`) |
| 인증서 비밀번호 | 화면에 안 보이는 게 정상입니다. 그냥 치고 Enter |
| 연락처 | 복무 신청에 들어갈 번호. 안 쓰면 Enter |
| 개인결재선 이름 | 나이스에 저장해 둔 결재선 프리셋 이름. 안 쓰면 Enter |
| 휴업일 시트 ID | 안 쓰면 Enter |

그다음 **브라우저가 자동으로 열립니다.**

1. 구글 로그인 → 계정 선택
2. ⭐ **「Google에서 확인하지 않은 앱」** 경고가 뜹니다 — **정상입니다.**
   내가 방금 만든 앱이라 구글이 아직 심사하지 않았을 뿐입니다.
   → **[계속]** 클릭 (예전 화면은 [고급] → [(프로젝트 이름)(으)로 이동] 이었습니다. 둘 중 보이는 쪽을 누르면 됩니다)
3. 권한 화면 — ⭐ **체크박스가 꺼진 채로 나옵니다.** 맨 위 **[모두 선택]** 을 체크한 뒤 **[계속]**
   (체크를 안 하고 넘어가면 캘린더를 못 읽어서 나중에 권한 오류가 납니다)
4. `인증 흐름이 완료되었습니다` 가 뜨면 브라우저를 닫습니다

터미널로 돌아오면 **출결 분류 캘린더 9개를 자동으로 만들어 줍니다.**

```
✅  '질병결석' 캘린더 생성
✅  '질병지각' 캘린더 생성
...
🎉  설정 완료!
```

이미 같은 이름의 캘린더가 있으면 새로 만들지 않고 **그걸 그대로 씁니다.**

---

## 7) 잘 됐는지 확인

구글 캘린더(https://calendar.google.com)를 열어 왼쪽 **「내 캘린더」** 목록에
`질병결석`, `질병조퇴` … 같은 캘린더가 생겼으면 성공입니다.

→ 다음은 **[03_캘린더-입력규칙.md](03_캘린더-입력규칙.md)**

## 막혔을 때

| 빨간 글씨 / 증상 | 뜻 | 해결 |
|---|---|---|
| `액세스 차단됨: 앱이 Google 인증 절차를 완료하지 않았습니다` | 테스트 사용자에 내 계정이 없다 | 3단계 5번 — 내 이메일을 테스트 사용자로 추가 |
| `oauth_client.json 파일이 없습니다` | 파일을 안 만들었거나 이름이 다르다 | 확장자까지 정확히 `oauth_client.json` 인지 확인 |
| `redirect_uri_mismatch` | 클라이언트 유형이 "웹"으로 만들어졌다 | 4단계에서 **데스크톱 앱**으로 다시 만들기 |
| 브라우저가 안 열린다 | 터미널에 주소가 찍혀 있다 | 그 주소를 복사해 브라우저에 붙여넣기 |
| 캘린더가 안 생긴다 | Calendar API를 안 켰다 | 2단계에서 **[사용]** 눌렀는지 확인 |
| 일주일쯤 지나면 구글 로그인 창이 또 뜬다 | 앱이 **「테스트 중」** 이라 열쇠가 7일 만에 만료됐다 | 3-1단계 — **[대상] → [앱 게시]** |
| 이름에 잘못된 문자가 포함되어 있습니다 | 프로젝트 이름에 한글을 넣었다 | 1단계 — 영어·숫자·하이픈으로 (예: `neis-attendance`) |
| 캘린더 권한 오류 | 동의 화면에서 체크박스를 안 켰다 | 다시 로그인해 **[모두 선택]** 체크 후 [계속] |

Claude Code를 쓰신다면 **빨간 글씨를 통째로 복사해서 붙여넣고 물어보세요.** 그게 제일 빠릅니다.
