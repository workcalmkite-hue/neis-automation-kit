# 3. 캘린더 입력 규칙

**이 문서가 제일 중요합니다.** 형식이 틀리면 도구가 그 일정을 아예 못 알아봅니다.

원칙은 하나입니다:
> **어떤 분류인지는 「캘린더 이름」이 정하고, 누가·언제인지는 「일정 제목」이 정한다.**

---

## 1. 캘린더는 분류별로 하나씩

설정 마법사가 아래 9개를 자동으로 만들어 줍니다.
**출결을 넣을 때는 해당 분류의 캘린더를 골라서** 일정을 만듭니다.

| 캘린더 이름 | 나이스에 들어가는 값 |
|---|---|
| `질병결석` | 질병 · 결석 |
| `질병지각` | 질병 · 지각 |
| `질병조퇴` | 질병 · 조퇴 |
| `미인정결석` | 미인정 · 결석 |
| `미인정지각` | 미인정 · 지각 |
| `미인정조퇴` | 미인정 · 조퇴 |
| `출석인정결석` | 출석인정 · 결석 |
| `출석인정지각` | 출석인정 · 지각 |
| `출석인정조퇴` | 출석인정 · 조퇴 |

> ⚠️ **다른 캘린더(개인 일정, 학교 일정 등)에 적으면 읽지 않습니다.** 반드시 위 캘린더에 넣으세요.

---

## 2. 제목 형식

```
{번호} {이름} {분류} (메모)
```

### 실제 예시

```
1 홍길동 출석인정결석
2 김철수 질병조퇴 (2교시~)
7 박지우 질병지각 (~2교시)
22 이서준 질병결석 (생리결석)
```

### 규칙

| | 설명 |
|---|---|
| **번호** | 출석번호. **뒤에 "번"을 붙이지 않습니다** |
| **띄어쓰기** | 번호와 이름 사이에 **공백 한 칸**이 꼭 있어야 합니다 |
| **이름** | 학생 이름. 띄어쓰기 없이 |
| **분류** | 캘린더 이름과 똑같이 적습니다. 도구는 이걸 읽지 않고 **캘린더 이름으로 판단**하지만, 나중에 사람이 볼 때 알아보기 위해 적습니다 |
| **메모** | 괄호 `()` 안에. 교시나 특이사항 |

### 이렇게 하면 안 읽힙니다

| ❌ 틀린 제목 | 왜 |
|---|---|
| `14번 김하늘 질병결석` | 번호 뒤에 "번"이 붙음 |
| `김하늘 질병결석` | 번호가 없음 |
| `14김하늘 질병결석` | 번호와 이름 사이에 공백이 없음 |
| `질병결석 - 14 김하늘` | 번호가 맨 앞이 아님 |

## 3. 교시 표기 — 틸드(`~`)의 위치가 방향입니다

**틸드가 "빠진 구간"을 가리킨다**고 기억하면 헷갈리지 않습니다.

### 조퇴: `숫자교시~` — 그 교시**부터** 없음

```
6 최민서 질병조퇴 (5교시~)
```
→ 4교시까지 있다가 **5교시부터 하교**했다는 뜻

### 지각: `~숫자교시` — 그 교시**까지** 없었음

```
7 박지우 질병지각 (~2교시)
```
→ 1~2교시는 결석, **3교시부터 등교**했다는 뜻

### 결석은 교시를 안 적습니다

```
12 정예린 질병결석
```

> 💡 교시를 안 적으면 도구가 임의로 정하지 않고 그대로 진행합니다.
> 교시가 중요한 조퇴·지각은 **꼭 적어주세요.**

---

## 4. 기간 — 결석만 여러 날이 됩니다

### 조퇴 · 지각

**하루짜리**로만 넣습니다. 여러 날에 걸치면 도구가 각 날짜에 같은 값을 넣어버립니다.

### 결석 (하루)

**종일 일정**으로 그날 하루만.

### 결석 (여러 날)

**종일 일정**으로 기간을 잡습니다.
구글 캘린더는 종일 일정의 **종료일을 하루 뒤로** 잡는 방식이라, 화면에서 드래그하면 알아서 맞습니다.
직접 날짜를 입력할 때만 주의하세요.

| 실제 결석 | 캘린더 시작 | 캘린더 종료 |
|---|---|---|
| 7/9 ~ 7/13 | `2026-07-09` | `2026-07-14` |
| 6/3 하루 | `2026-06-03` | `2026-06-04` |

> **주말은 자동으로 건너뜁니다.** 7/9(목)~7/13(월)로 넣으면 토·일은 빠지고 목·금·월만 입력됩니다.
> 휴업일도 건너뛰려면 [설정에서 휴업일 시트](02_구글-연동.md)를 연결하세요.

---

## 5. 같은 학생이 하루에 두 건이면

지각 + 조퇴처럼 한 날에 둘 다 있을 수 있습니다. **둘 다 넣으면 됩니다.**

```
(질병지각 캘린더)  7 박지우 질병지각 (~2교시)
(질병조퇴 캘린더)  7 박지우 질병조퇴 (6교시~)
```

도구가 **빠진 시간이 짧은 것부터 입력하고, 가장 많이 빠진 건을 마지막에** 넣습니다.
나이스가 마지막에 입력한 값을 최종 상태로 잡기 때문입니다. 순서를 신경 쓰지 않으셔도 됩니다.

## 6. Claude Code로 넣기 (더 편한 방법)

캘린더 화면을 열지 않고 **말로 시킬 수 있습니다.**

```
26번 임하준 7월 9일부터 13일까지 인정결석이야. 캘린더에 넣어줘
```

Claude Code가 알아서
- `출석인정결석` 캘린더를 고르고
- 제목을 `26 임하준 출석인정결석` 형식으로 바꾸고
- 종료일을 `2026-07-14`(하루 뒤)로 넣습니다

말한 그대로 제목에 넣지 않도록 `.claude/skills/출결등록` 에 규칙을 적어뒀습니다.

> 구글 캘린더 MCP가 연결돼 있어야 합니다. 없으면 캘린더 화면에서 직접 넣으세요 — 결과는 같습니다.

---

## 7. 넣고 나서

```powershell
.\.venv\Scripts\python.exe main.py
```

또는 Claude Code에서 `/나이스출결`.

처음이라 걱정되면 **`--dry-run`** 을 붙이세요. 목록만 보여주고 **나이스는 아예 열지 않습니다.**

```powershell
.\.venv\Scripts\python.exe main.py --dry-run
```

실행하면 **먼저 무엇을 넣을지 목록으로 보여줍니다.** 여기서 오타나 빠진 걸 확인할 수 있습니다.

```
📊  3개 날짜, 총 4건

  09/02 — 1번 홍길동(출석인정결석)
  09/03 — 2번 김철수(질병조퇴) / 7번 박지우(질병지각)
  09/05 — 22번 이서준(질병결석)
```

**끝난 뒤에는 나이스 화면에서 실제로 맞게 들어갔는지 눈으로 확인하세요.**
어긋난 곳을 찾고 싶으면:

```powershell
.\.venv\Scripts\python.exe verify_attendance.py 2026-09-01 2026-09-30
```

읽기만 하고 아무것도 고치지 않습니다.
