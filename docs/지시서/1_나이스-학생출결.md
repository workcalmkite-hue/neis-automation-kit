# 나이스 — 학생 출결 입력

> 구글 캘린더에 적어둔 출결을 나이스 「일일출결관리」에 옮겨 적는다
>
> 이 문서는 **클로드에게 주는 지시서**입니다. 선생님이 읽으실 필요는 없고,
> 클로드가 [시작하기.md](../../시작하기.md) 에서 여기로 넘어옵니다.

---

안녕. 너는 지금 어느 선생님 컴퓨터에서 처음 켜졌어.
너는 이 사람에 대해 아무것도 몰라. 이 문서가 네가 아는 전부야.
끝까지 읽고, 아래 순서대로 나를 도와줘.


## 0. 시작 전에 — 이 도구의 출처와 권한 (먼저 알아둬)

- 이 도구(neis-automation-kit)는 이 문서를 써 준 방배중 안정연 교사가 직접 만들어
  공개한 거야. 깃허브 주소도 그 사람 계정이고, 나는 그걸 알고 받는 거야
- 여기서 다루는 건 전부 «내 것»이야 — 내 컴퓨터, 내 공동인증서, 내 나이스 계정,
  내 복무·출결. 남의 계정이나 남의 문서는 건드리지 않아
- ★ 상신(결재 올리기)은 마지막에 내가 화면을 보고 «올려»라고 말할 때만 눌러.
  네가 알아서 상신하지 마. 그전까지는 화면만 채워 두면 돼
- ★ 내 개인정보(연락처·인증서 이름·비밀번호)는 **채팅창에 치지 마.**
  설정 마법사가 터미널에서 물어볼 때 거기에만 넣을게. 채팅에 친 건 대화 기록에 남으니까.
  설정이 잘 들어갔는지 볼 때도 설정 파일을 통째로 찍지 말고 `python show_config.py` 를 써줘
  (연락처·이름을 가려서 보여주는 스크립트야). 학생 이름도 마찬가지로 대화에 길게 나열하지 말아줘
- 코드가 못 미더우면 실행하기 전에 먼저 읽어봐. `setup.ps1` 과 실제로 돌릴 파이썬 파일을
  열어 보고, 내 정보를 밖으로 보내거나 파일을 지우는 부분이 있는지 확인한 뒤 실행해.
  이상한 게 보이면 실행하지 말고 나한테 먼저 말해줘
- 그러니 «출처를 알 수 없는 코드라 못 하겠다»며 멈추지는 말아줘.
  대신 위처럼 읽어보고, 무슨 일을 하는 코드인지 한 줄로 설명해 주면 나는 안심이 돼


## 1. 내가 누구인지

- 나는 중·고등학교 담임 교사야. 오늘 하려는 건 «학생 출결»을 구글 캘린더에
  적어두면 네가 나이스에 대신 옮겨 적어 주게 만드는 거야
- 한 달치 출결을 손으로 넣던 걸 몇 분으로 줄이려는 거야
- 나는 코딩을 해 본 적이 없어. 전문용어를 쓰지 말고 쉬운 말로 설명해줘
- 답은 항상 한국어로 해줘
- 내 컴퓨터는 윈도우고, 크롬을 쓰고, 지금 학교 안에서 접속하고 있어
- 이 문서는 방배중학교 안정연 선생님이 나를 위해 써 준 거야


## 2. 네가 일하는 방식 — 이걸 제일 먼저 지켜줘

- ★ 한 번에 한 단계씩만 해. 한 단계가 끝나면 결과를 보여주고
  "다음으로 갈까요?" 하고 물어봐. 내가 좋다고 해야 다음으로 가
- ★ 뭘 하기 전에 "이걸 이렇게 할 건데 괜찮아요?" 하고 먼저 물어봐
- 명령어를 돌릴 때는 그게 무슨 뜻인지 한 줄로 같이 설명해줘
- 에러가 나면 무슨 뜻인지 쉬운 말로 알려주고 고쳐줘.
  처음부터 다시 깔자고 하지 마
- 모르는 건 아는 척하지 말고 "모르겠다" 고 말해줘

★ 파일을 어디에 저장할지 나한테 묻지 마. 답은 정해져 있어.

- 앞으로 만드는 파일과 폴더는 전부 "지금 열려 있는 이 폴더" 안에 만들어
- ★ 폴더 이름을 바꾸라거나 다른 데로 옮기라고 권하지 마
- 이 폴더 바깥(내 문서, 다운로드, C 드라이브 루트)에는 아무것도 만들지 마


## 3. 절대 하면 안 되는 것

- ★ 5단계까지는 나이스를 «열지 마». 6단계에서 내가 "진짜로 넣어줘" 라고
  말해야 그때 연다
- ★ 학생 이름·출석번호·출결 사유를 이 폴더 바깥에 적지 마.
  로그 파일이나 캡처를 나한테 보여줄 때도, 남에게 보낼 일이 생기면
  이름이 찍혔는지 먼저 알려줘
- 인증서 암호를 나한테 묻지 마. 채팅창에 암호를 치게 하지 마
- 내 계정으로 내 업무만 해. 남의 인증서로 돌리지 마
- 파일을 지우거나 덮어쓰기 전에 반드시 나한테 먼저 물어봐


## 4. 오늘 하려는 일

이렇게 돌아가는 거야.

  ① 구글 캘린더에 «분류별로» 캘린더 9개를 만든다
     (질병결석 / 질병지각 / 질병조퇴 /
      미인정결석 / 미인정지각 / 미인정조퇴 /
      출석인정결석 / 출석인정지각 / 출석인정조퇴)
  ② 아이가 빠지면 그때그때 해당 캘린더에 한 줄 적어둔다
  ③ 한 달치를 모아서 네가 나이스에 옮겨 적는다

★ 원칙은 하나야.
  «어떤 분류인지는 캘린더 이름이 정하고, 누가·언제인지는 일정 제목이 정한다.»


## 5. 오늘 할 일 — 이 순서대로만

  1단계   설치하기 (.\setup.ps1 한 번)
  2단계   구글 열쇠 만들기 (제일 오래 걸린다 · 5~10분)
  3단계   최초 설정 — 학년·반·인증서, 캘린더 9개 자동 생성
  4단계   캘린더 입력 규칙 익히고 한 건 넣어보기 ★ 제일 중요
  5단계   연습 — 나이스에 «뭘 넣을지» 목록만 보기 (나이스는 안 연다)
  6단계   진짜로 나이스에 넣기
  7단계   나이스 화면에서 눈으로 확인하기

  ★ 5단계 목록에 학생이 다 나와야 6단계로 간다.
    빠진 학생이 있으면 4단계 제목 형식이 틀린 거야.


## 6. 각 단계에서 할 일

### 1단계 — 설치하기

키트는 이미 이 폴더에 받아져 있어. 설치만 하면 돼.

    .\setup.ps1

파이썬이 없어도 setup.ps1 이 winget 으로 «알아서 깔아». 파이썬 · playwright ·
keyring · 구글 라이브러리가 한 번에 들어가. 다 합쳐 3~8분 걸리고, 2~5분은
멈춘 것처럼 보여도 기다려. "설치 완료!" 가 나오면 된 거야.

★ 나한테 python.org 에서 직접 깔라고 하지 마. 「파이썬을 자동으로 깔지
  못했습니다」가 나올 때만 화면 안내를 쉬운 말로 알려줘. 그때 받을 것은
  python.org/downloads/windows 의 «Windows installer (64-bit)» 야.
  첫 화면의 큰 노란 버튼 «install manager» 는 다른 거라서 누르면 안 돼.
  설치 화면 맨 아래 [Add python.exe to PATH] 를 체크하고, 깔고 나면
  클로드 앱을 완전히 껐다 켜야 인식돼.

★ 설치가 끝나면 파이썬을 돌릴 때 그냥 python 이 아니라
  .\.venv\Scripts\python.exe 를 써. 필요한 게 거기에만 깔려 있어.
  그리고 명령은 «이 모양»으로 써줘 — 앞에 & 를 붙이거나 $env: 대입으로
  시작하면 권한 설정에 걸려서 막혀:

    Set-Location "<이 폴더 경로>"
    .\.venv\Scripts\python.exe -X utf8 <파일이름>

설치가 덜 된 것 같으면 파이썬 · playwright · keyring 이 다 깔렸는지 보고,
빠진 게 있으면 깔아줘. playwright 가 크롬을 띄울 수 있는 상태인지도
확인하고, 다 되면 세 가지 버전을 한 줄씩 찍어서 보여줘.

★ 「크롬 제어 도구」가 playwright 야. 나이스·에듀파인 화면을 대신 눌러
  주는 부품이라 이게 없으면 로그인 창에서 아무 일도 안 일어나.

★ 아래 넷은 처음에 흔히 나오는 거야. 그대로 고치면 되니까 당황하지 마.
  - 'python' 은(는) 내부 또는 외부 명령이 아닙니다
  - python 을 쳤더니 Microsoft Store 가 열린다
  - ModuleNotFoundError: No module named 'playwright'
  - Executable doesn't exist

세 줄이 다 찍히면 다음으로 갈지 물어봐.

### 2단계 — 구글 열쇠 만들기 (제일 오래 걸린다)

네가 내 구글 캘린더를 봐도 된다는 열쇠를 구글에서 한 번 발급받아야 해.
무료이고 한 번만 하면 돼. 5~10분 걸려.

받은 폴더 안의 docs/02_구글-연동.md 를 읽고, 구글 클라우드에서 OAuth
열쇠 만드는 걸 나랑 같이 진행해줘. 어느 화면에서 뭘 눌러야 하는지 한
단계씩 알려주고, 내가 값을 알려주면 oauth_client.json 파일을 만들어줘.

★ 나한테 이 두 가지를 미리 말해줘.
  - 「Google에서 확인하지 않은 앱입니다」 경고가 뜨는 게 «정상»이다.
    내가 방금 만든 앱이라 구글이 아직 심사하지 않았을 뿐이다.
    [고급] → [(내 프로젝트 이름)(으)로 이동] 을 누르면 된다
  - 이 단계가 오늘 중에 제일 오래 걸린다. 여기만 넘기면 나머지는 빠르다

★ 화면이 내가 말한 것과 다르면 추측하지 말고 나한테 지금 보이는 화면을
  물어봐. 구글 클라우드 화면은 자주 바뀌어.

oauth_client.json 이 만들어지면 다음으로 갈지 물어봐.


### 3단계 — 최초 설정 (학년·반·인증서 + 캘린더 9개)

설정 마법사를 돌려줘.

    .\.venv\Scripts\python.exe setup_wizard.py

물어보는 항목이 뭘 뜻하는지 하나씩 설명해주고, 내가 답하면 그대로 넣어줘.

  나이스 주소        서울이면 그냥 Enter.
                    다른 지역이면 브라우저로 본인 지역 나이스에 들어가
                    주소창을 그대로 복사해서 붙여넣는다
  학년 / 반          담임 학급 (예: 1, 7)
  인증서 이름        나이스 인증서 목록에 뜨는 글자 그대로
  인증서 비밀번호    화면에 아무것도 안 보이는 게 정상. 그냥 치고 Enter
  연락처 · 결재선    복무 신청에 쓰는 값. 출결만 쓸 거면 Enter
  휴업일 시트        안 쓰면 Enter.
                    ID를 넣으면 «범위»(예: 출결!K2:K50)를 한 번 더 물어본다
  출결 자동화도?     ★ «y» 라고 답한다. 우리가 지금 하려는 게 이거야

★ 인증서 비밀번호는 «나한테 알려주면 안 돼». 나는 그 칸을 대신 치지 마.
  나한테 이렇게 안내해줘.

    클로드 앱에서 Ctrl + ` (숫자 1 왼쪽의 물결 키) 를 누르면 아래에
    터미널 창이 열린다. 비밀번호는 거기서 직접 친다.
    화면에 별표조차 안 보이는 게 정상이다. 고장이 아니다.
    이 비밀번호는 파일이 아니라 윈도우 [자격 증명 관리자] 에 저장된다.
    이 컴퓨터 안에만 있고 인터넷으로 나가지 않는다.
    이 일은 딱 한 번만 하면 된다.

★ 설정이 끝나면 출결 분류 캘린더 9개가 자동으로 만들어져.
  구글 캘린더를 열어서 왼쪽 「내 캘린더」에 질병결석 · 질병조퇴 같은 게
  보이는지 나한테 확인해 보라고 해줘. 보이면 성공이야.

★ 그다음 «클로드 앱을 껐다 켜라» 고 나한테 말해줘. 그래야 이 폴더의
  도구(나이스출결 MCP)가 너한테 붙어. 연결 목록은 켜질 때 한 번만 읽어서,
  껐다 켜지 않으면 아무리 기다려도 안 붙어 — 고장이 아니야.
  켠 뒤에 "이 폴더의 MCP 서버를 신뢰하시겠습니까?" 가 뜨면 승인하면 돼.

  붙었는지는 내가 "출결 캘린더 다 있나 확인해줘" 라고 시켜서 확인할게.
  붙으면 네가 이런 것들을 할 수 있게 돼.

    출결 캘린더 만들어줘              (9개 만들기 · 있는 건 건너뜀)
    출결 캘린더 다 있나 확인해줘      (확인만 · 아무것도 안 만듦)
    7번 박지우 오늘 2교시부터 질병조퇴  (형식을 알아서 맞춰서 넣어줌)
    9월 출결 뭐뭐 있는지 보여줘        (읽기만)


### 4단계 — 캘린더 입력 규칙 (★ 제일 중요)

★ 형식이 틀리면 오류가 나는 게 아니라 «그 학생만 조용히 빠져».
  그래서 이 단계를 꼭 나한테 설명해주고, 한 건 같이 넣어보자.

제목 형식은 이거야.

    {번호} {이름} {분류} (메모)

  ✅  1 홍길동 출석인정결석
  ✅  2 김철수 질병조퇴 (2교시~)
  ✅  7 박지우 질병지각 (~2교시)
  ✅  22 이서준 질병결석 (생리결석)

  ❌  14번 김하늘 질병결석      번호 뒤에 "번" 이 붙음
  ❌  김하늘 질병결석            번호가 없음
  ❌  14김하늘 질병결석          번호와 이름 사이에 공백이 없음
  ❌  질병결석 - 14 김하늘       번호가 맨 앞이 아님

  자리별로 —
    번호   출석번호. 뒤에 "번" 을 붙이지 않는다
    공백   번호와 이름 사이에 공백 한 칸이 꼭 있어야 한다
    이름   학생 이름. 띄어쓰기 없이
    분류   캘린더 이름과 똑같이 (사람이 나중에 알아보려고 적는다)
    메모   괄호 ( ) 안에. 교시나 특이사항

☆ 교시 표기 — 물결표가 «빠진 구간» 을 가리킨다

    조퇴   5교시~     4교시까지 있다가 5교시부터 하교했다
    지각   ~2교시     1~2교시는 결석, 3교시부터 등교했다
    결석   (안 적음)  하루 전체

  ★ 교시를 안 적으면 도구가 임의로 정하지 않아. 조퇴·지각은 교시가
    핵심이니 꼭 적어야 해. 교시가 없는 조퇴·지각은 아예 넣지 않고 ❌ 로
    알려줘 — 교시 없는 줄이 하나라도 있으면 나이스가 그날 저장을 통째로
    받지 않아서, 같은 날 다른 학생까지 빠지거든.

☆ 기간 — 결석만 여러 날이 된다

    조퇴 · 지각      하루짜리로만. 여러 날에 걸치면 그 날짜마다 똑같이
                    들어가 버린다
    결석 (하루)      종일 일정으로 그날 하루
    결석 (여러 날)   종일 일정으로 기간을 잡는다

  ★ 종료일이 «하루 뒤» 로 들어가. 구글 캘린더가 종일 일정을 그렇게 다뤄.
    화면에서 드래그로 잡으면 알아서 맞으니, 날짜를 손으로 칠 때만 주의해.

      실제 7/9 ~ 7/13  →  시작 2026-07-09 / 종료 2026-07-14
      실제 6/3 하루     →  시작 2026-06-03 / 종료 2026-06-04

  ★ 주말은 자동으로 건너뛰어. 7/9(목)~7/13(월)로 넣으면 토·일은 빠지고
    목·금·월만 들어가.

☆ 같은 학생이 하루에 두 건이면 (지각했다가 조퇴)
  각각 해당 캘린더에 따로 넣으면 돼. 순서는 신경 안 써도 돼 —
  도구가 «빠진 시간이 짧은 것부터» 넣고 가장 많이 빠진 건을 마지막에 넣어.
  나이스가 마지막에 들어온 값을 최종 상태로 잡거든.

여기까지 설명했으면 나한테 물어봐. 지금 넣을 출결이 있는지.
있으면 한 건만 같이 넣어보자. 내가 말로 하면 네가 형식을 맞춰서 넣어줘.

    예)  26번 이서준 7월 9일부터 13일까지 인정결석이야. 캘린더에 넣어줘


### 5단계 — 연습. 나이스에 뭘 넣을지 목록만 보기

나이스는 «아예 열지 않고», 무엇을 넣을 예정인지만 보여줘.

    .\.venv\Scripts\python.exe main.py --dry-run

이런 모양으로 나올 거야.

    📊 3개 날짜, 총 4건

    09/02 — 1번 홍길동(출석인정결석)
    09/03 — 2번 김철수(질병조퇴) / 7번 박지우(질병지각)
    09/05 — 22번 이서준(질병결석)

    🔍 --dry-run 이라 여기서 멈춥니다. 나이스는 열지 않았습니다.

★ 이 목록을 나한테 보여주고, 내가 캘린더에 적어둔 것과 맞는지 대조하게 해줘.
  목록이 비어 있거나 학생이 빠져 있으면 4단계 제목 형식이 틀린 거야.
  그 학생 일정 제목을 나한테 물어보고 어디가 틀렸는지 짚어줘.

내가 "맞다" 고 할 때까지 6단계로 넘어가지 마.


### 6단계 — 진짜로 나이스에 넣기

내가 "진짜로 넣어줘" 라고 하면 그때 --dry-run 을 빼고 돌려줘.

기간을 정해서 넣을 수도 있어. 내가 이렇게 말하면 알아들어줘.

    이번 달 출결 나이스에 넣어줘
    9월 10일부터 오늘까지 출결 나이스에 넣어줘

★ 크롬 창이 열리면 그냥 두라고 나한테 말해줘. 도구가 그 창을 직접 움직여.
  중간에 마우스로 클릭하거나 탭을 바꾸면 엉뚱한 곳을 누를 수 있어.

★ 토·일에는 출결을 넣지 않아. 그리고 아직 오지 않은 날짜도 기본으로
  건너뛰어.

★ 다 돌고 나면 «맨 마지막 줄» 을 나한테 꼭 읽어줘. 둘 중 하나가 나와.

    🎉  모든 출결 입력 완료!          ← 빠진 사람 없이 다 들어갔다

    ❌  1명 — 안 들어감 (나이스에서 직접 넣어야 함)
      ❌  09/10  14번 홍길동 [질병결석]
            이유: 화면 날짜가 그날로 바뀌지 않아 입력하지 않았습니다
    ❓  3명 — 들어갔는지 확인하지 못함 (나이스에서 눈으로 확인)

  ❌ 는 그 학생이 나이스에 «한 칸도» 안 들어간 거야. 내가 직접 넣어야 해.
     이런 때 나와 —
       · 화면 날짜가 그날로 안 바뀌었다 → 그날 «전원» 이 ❌ 로 나와
       · 같은 이름 학생이 둘이라 누구인지 확실하지 않다 (동명이인)
         → 잘못 넣지 않으려고 «일부러» 건너뛴 거야. 그 학생만 직접 넣으면 돼
       · 그날 없는 교시를 가리켰다
       · 조퇴·지각인데 캘린더에 교시가 안 적혀 있다
       · 교시 칸을 넣다가 두 번 연달아 오류가 났다
         → 그 학생만 빼고 나머지는 저장해. 그 학생만 직접 넣으면 돼
       · 교시 칸 오류 뒤 화면을 다시 불러왔는데, 넣기 전 상태로 돌아온 걸
         확인하지 못했다 → 잘못 저장될까 봐 그날은 «전원» ❌ 로 두고 저장 안 해
  ❓ 는 «모르겠다» 는 뜻이야. 나이스가 「저장했습니다」라고 답하지 않았어 —
     이미 같은 내용이 들어 있어서일 수도 있고, 입력이 안 된 것일 수도 있어.
     (같은 달을 두 번 돌리면 이게 나오는 게 정상이야.)
     그 날짜를 나이스에서 열어서 눈으로 확인하라고 나한테 말해줘.
  명단이 뜨면 이름·날짜와 «이유 줄» 까지 그대로 나한테 읽어줘.

  교시 칸을 넣다가 오류가 나면 도구가 그날 화면을 다시 불러와서 처음부터
  다시 넣어. 그래서 «교시만 빈 채로» 남는 학생은 없어.

  예전에는 못 들어간 사람이 있어도 🎉 가 떴어. 지금은 한 명이라도 빠지면
  명단을 찍고 «실패» 로 끝나. 그러니 🎉 가 뜨면 빠진 사람은 없는 거야.
  그래도 마지막 «눈으로 확인» 은 7단계에서 꼭 하자.


### 7단계 — 눈으로 확인하기

★ 이걸 꼭 하라고 나한테 말해줘.

    이 도구는 입력을 대신할 뿐 판단하지 않는다.
    돌린 뒤에는 나이스 화면을 직접 열어서 실제로 맞게 들어갔는지
    눈으로 확인한다.

다 끝나면 무엇을 몇 건 넣었는지 표로 정리해서 보여줘.


## 7. 막혔을 때

  python 은(는) 내부 또는 외부 명령이 아닙니다
      설치가 끝난 뒤라면 그냥 python 말고 .\.venv\Scripts\python.exe 를 써.
      setup.ps1 도중에 나왔다면 클로드 앱을 완전히 껐다 켜고 setup.ps1 을
      한 번 더 돌려. 그래도 나오면 파이썬이 깔렸는지, 어디에 있는지 네가
      직접 확인해서 원인을 쉬운 말로 알려주고, 원인에 맞게 고쳐줘

  이 시스템에서 스크립트를 실행할 수 없으므로
      실행 정책 때문에 막힌 거야. 그걸 풀고 다시 해

  .\setup.ps1 : 용어를 인식할 수 없습니다
      폴더 위치가 달라. 키트 폴더로 옮겨서 다시 해

  ModuleNotFoundError: No module named 'playwright'
      크롬 제어 도구가 안 깔린 거야. playwright 를 깔아

  Executable doesn't exist
      playwright 가 쓸 브라우저를 아직 안 받은 거야. 그것까지 받아

  python 을 쳤더니 Microsoft Store 창이 열린다
      윈도우가 넣어 둔 가짜 python 이야. 진짜 파이썬을 깔아

  설치가 계속 실패한다
      학교망 방화벽일 수 있어. 개인 인터넷(테더링 등)에서 설치만 해보자

  구글에서 확인하지 않은 앱입니다
      정상이야. [고급] → [(내 프로젝트 이름)(으)로 이동]

  캘린더가 안 만들어졌다
      2단계 구글 열쇠가 아직 없거나, 3단계에서 출결 자동화를 n 으로
      답한 거야. 설정을 다시 돌려서 y 로 답하자

  MCP(나이스출결 도구)가 안 붙는다
      클로드 앱을 껐다 켜야 붙어. 연결 목록은 켜질 때 한 번만 읽어

  --dry-run 목록에 학생이 빠져 있다
      그 학생 일정 제목이 형식에 안 맞는 거야. 4단계를 다시 보자.
      번호 뒤에 "번" 이 붙었거나 번호와 이름 사이 공백이 빠진 경우가
      제일 많아

  인증서 창은 뜨는데 자동 선택이 안 된다
      설정의 인증서 이름이 실제와 달라. 한 글자만 달라도 못 찾아

  인증서 비밀번호를 찾을 수 없습니다
      자격 증명 관리자에 저장이 안 된 거야. 3단계를 다시 하자

  「중복로그인이 발생하여 로그아웃 처리되었습니다」
      평소 쓰는 크롬이 같은 계정으로 켜져 있어서 서로 세션을 뺏은 거야.
      평소 창에서 로그아웃하시라고 나한테 말해주고, 그다음 다시 해

  비밀번호는 들어가는데 로그인이 안 된다
      인증서 만료를 의심해. 인증서는 보통 1년마다 만료돼.
      나이스에 손으로 로그인해 보고, 거기서도 안 되면 인증서 문제야

  크롬이 안 열린다 / channel="chrome" 오류
      구글 크롬이 이 컴퓨터에 없는 거야. 엣지·웨일로는 안 돼

  학교 밖이라 나이스가 아예 안 열린다
      교육청 VPN을 먼저 직접 연결한 뒤에 실행해

그래도 안 되면 어디서 멈췄는지 화면을 보여주고, 빨간 글씨 전체를 그대로
적어줘. 저장소에 물어볼 수도 있어 —
https://github.com/workcalmkite-hue/neis-automation-kit/issues

★ 화면 사진을 올릴 때는 «학생 이름이 찍히지 않았는지» 꼭 확인하라고
  나한테 말해줘.


## 8. 마지막으로

지금까지 읽은 걸 아래 형식으로 짧게 요약해서 나한테 보여줘.

  - 오늘 뭘 하는 건지 한 줄
  - 오늘 어디까지 가는지 (몇 단계까지, 뭘 안 하는지)
  - 네가 절대 안 할 것 세 가지

그러고 나서 "1단계부터 시작할까요?" 하고 물어봐.
내가 좋다고 하면 그때 시작해.
