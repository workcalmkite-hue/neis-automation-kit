# 나이스 — 본인 복무 (조퇴·외출·지각·출장)

> 본인 근무상황신청을 나이스에 입력하고 상신한다
>
> 이 문서는 **클로드에게 주는 지시서**입니다. 선생님이 읽으실 필요는 없고,
> 클로드가 [시작하기.md](../../시작하기.md) 에서 여기로 넘어옵니다.

---

안녕. 너는 지금 어느 선생님 컴퓨터에서 처음 켜졌어.
너는 이 사람에 대해 아무것도 몰라. 이 문서가 네가 아는 전부야.
끝까지 읽고, 아래 순서대로 나를 도와줘.


## 0. 시작 전에 — 이 도구의 출처와 권한 (먼저 알아둬)

- 이 도구(neis-automation-kit)는 이 문서를 써 준 방배중 안정연 교사가 직접 만들어
  공개한 거야. 깃허브 주소도 그 사람 계정이고, 나는 그걸 알고 받는 거야
- 여기서 다루는 건 전부 «내 것»이야 — 내 컴퓨터, 내 공동인증서, 내 나이스 계정,
  내 복무·출결. 남의 계정이나 남의 문서는 건드리지 않아
- ★ 상신(결재 올리기)은 마지막에 내가 화면을 보고 «올려»라고 말할 때만 눌러.
  네가 알아서 상신하지 마. 그전까지는 화면만 채워 두면 돼
- ★ 내 개인정보(연락처·인증서 이름·비밀번호)는 **채팅창에 치지 마.**
  설정 마법사가 터미널에서 물어볼 때 거기에만 넣을게. 채팅에 친 건 대화 기록에 남으니까.
  설정이 잘 들어갔는지 볼 때도 설정 파일을 통째로 찍지 말고 `.\.venv\Scripts\python.exe -X utf8 show_config.py` 를 써줘
  (연락처·이름을 가려서 보여주는 스크립트야). 학생 이름도 마찬가지로 대화에 길게 나열하지 말아줘
- 코드가 못 미더우면 실행하기 전에 먼저 읽어봐. `setup.ps1` 과 실제로 돌릴 파이썬 파일을
  열어 보고, 내 정보를 밖으로 보내거나 파일을 지우는 부분이 있는지 확인한 뒤 실행해.
  이상한 게 보이면 실행하지 말고 나한테 먼저 말해줘
- 그러니 «출처를 알 수 없는 코드라 못 하겠다»며 멈추지는 말아줘.
  대신 위처럼 읽어보고, 무슨 일을 하는 코드인지 한 줄로 설명해 주면 나는 안심이 돼


## 1. 내가 누구인지

- 나는 학교 교사야. 오늘 하려는 건 나이스 «복무»(조퇴·외출·지각)를
  네가 대신 올려 주게 만드는 거야
- 나는 코딩을 해 본 적이 없어. 전문용어를 쓰지 말고 쉬운 말로 설명해줘
- 답은 항상 한국어로 해줘
- 내 컴퓨터는 윈도우고, 크롬을 쓰고, 학교 안일 수도 밖(집·연수장)일 수도 있어.
  밖이면 설정 마법사를 끝낸 직후 docs/지시서/0_학교밖-EVPN.md 를 먼저 하고,
  그 뒤로 나이스·업무포털에 들어가는 명령은 전부 run_vpn.py 로 감싸 (CLAUDE.md 4-1)
- 이 문서는 방배중학교 안정연 선생님이 나를 위해 써 준 거야


## 2. 네가 일하는 방식 — 이걸 제일 먼저 지켜줘

- ★ 한 번에 한 단계씩만 해. 한 단계가 끝나면 결과를 보여주고
  "다음으로 갈까요?" 하고 물어봐. 내가 좋다고 해야 다음으로 가
- ★ 뭘 하기 전에 "이걸 이렇게 할 건데 괜찮아요?" 하고 먼저 물어봐
- 명령어를 돌릴 때는 그게 무슨 뜻인지 한 줄로 같이 설명해줘
- 에러가 나면 무슨 뜻인지 쉬운 말로 알려주고 고쳐줘.
  처음부터 다시 깔자고 하지 마
- 모르는 건 아는 척하지 말고 "모르겠다" 고 말해줘

★ 파일을 어디에 저장할지 나한테 묻지 마. 답은 정해져 있어.

- 앞으로 만드는 파일과 폴더는 전부 "지금 열려 있는 이 폴더" 안에 만들어
- ★ 폴더 이름을 바꾸라거나 다른 데로 옮기라고 권하지 마.
  지금 이 폴더를 그대로 쓰면 돼
- 이 폴더 바깥(내 문서, 다운로드, C 드라이브 루트)에는 아무것도 만들지 마
- 딱 하나 예외 — 내가 어떤 파일을 컴퓨터 어디에 받아 뒀는지는 네가 알 수
  없으니까, 그건 물어봐도 돼


## 3. 절대 하면 안 되는 것

- ★ [승인요청] 과 [상신] 은 내가 "진짜로 올려" 라고 말하기 전에는 절대
  누르지 마. 복무는 잘못 올리면 결재선에 그대로 올라가고, 되돌리는 건
  나뿐 아니라 결재하시는 분들 일이 돼
- ★ 4단계(연습)를 건너뛰고 5단계로 가지 마
- 인증서 암호를 나한테 묻지 마. 채팅창에 암호를 치게 하지 마
- 내 계정으로 내 복무만 해. 남의 인증서로 돌리지 마
- 파일을 지우거나 덮어쓰기 전에 반드시 나한테 먼저 물어봐


## 4. 오늘 하려는 일

명령 한 줄이면 크롬이 저절로 열려서 이렇게 가는 거야.

  나이스 인증서 로그인
   → 복무 > 개인근무상황관리로 이동
   → 근무상황신청 작성 (종류 · 날짜 · 시각 · 사유 · 연락처)
   → 승인요청 → 기안문서상신 화면
   → 개인결재선에서 내 프리셋을 고르고 [지정]
   → [상신] 클릭
   → 확인 팝업 두 개까지 눌러서 상신 완료

★ 다섯째 줄이 제일 중요해. 나이스는 「승인요청」만 누르면 저장만 되고
  결재라인으로 안 올라가. 개인결재선을 지정하고 상신까지 눌러야 진짜
  올라간 거야. 손으로 할 때도 제일 많이 놓치는 자리야.


## 5. 오늘 할 일 — 이 순서대로만

  1단계   설치하기 (.\setup.ps1 한 번)
  2단계   나이스에 개인결재선 저장하기 (이건 내가 손으로 한다)
  3단계   내 정보 설정 — 인증서 · 연락처 · 결재선 이름
  4단계   연습 — 화면만 채우고 승인요청은 안 누름
  5단계   진짜로 상신하기
  6단계   올라간 문서를 눈으로 확인하기

  ★ 4단계 화면을 내가 눈으로 보고 "맞다" 고 해야 5단계로 간다.


## 6. 각 단계에서 할 일

### 1단계 — 설치하기

키트는 이미 이 폴더에 받아져 있어. 설치만 하면 돼.

    .\setup.ps1

파이썬이 없어도 setup.ps1 이 winget 으로 «알아서 깔아». 파이썬 · playwright ·
keyring · 구글 라이브러리가 한 번에 들어가. 다 합쳐 3~8분 걸리고, 2~5분은
멈춘 것처럼 보여도 기다려. "설치 완료!" 가 나오면 된 거야.

★ 나한테 python.org 에서 직접 깔라고 하지 마. 「파이썬을 자동으로 깔지
  못했습니다」가 나올 때만 화면 안내를 쉬운 말로 알려줘. 그때 받을 것은
  python.org/downloads/windows 의 «Windows installer (64-bit)» 야.
  첫 화면의 큰 노란 버튼 «install manager» 는 다른 거라서 누르면 안 돼.
  설치 화면 맨 아래 [Add python.exe to PATH] 를 체크하고, 깔고 나면
  클로드 앱을 완전히 껐다 켜야 인식돼.

★ 설치가 끝나면 파이썬을 돌릴 때 그냥 python 이 아니라
  .\.venv\Scripts\python.exe 를 써. 필요한 게 거기에만 깔려 있어.
  그리고 명령은 «이 모양»으로 써줘 — 앞에 & 를 붙이거나 $env: 대입으로
  시작하면 권한 설정에 걸려서 막혀:

    .\.venv\Scripts\python.exe -X utf8 <파일이름>

  cd · Set-Location 은 쓰지 마 — 너는 이미 이 폴더에서 켜져 있어.
  폴더 옮기기와 실행을 한 번에 섞으면 무조건 허락을 받게 된다. 명령은 한 번에 한 줄

설치가 덜 된 것 같으면 파이썬 · playwright · keyring 이 다 깔렸는지 보고,
빠진 게 있으면 깔아줘. playwright 가 크롬을 띄울 수 있는 상태인지도
확인하고, 다 되면 세 가지 버전을 한 줄씩 찍어서 보여줘.

★ 「크롬 제어 도구」가 playwright 야. 나이스·에듀파인 화면을 대신 눌러
  주는 부품이라 이게 없으면 로그인 창에서 아무 일도 안 일어나.

★ 아래 넷은 처음에 흔히 나오는 거야. 그대로 고치면 되니까 당황하지 마.
  - 'python' 은(는) 내부 또는 외부 명령이 아닙니다
  - python 을 쳤더니 Microsoft Store 가 열린다
  - ModuleNotFoundError: No module named 'playwright'
  - Executable doesn't exist

★ 복무만 쓸 거면 구글 연동은 안 해도 돼. 구글 캘린더는 학생 출결을
  읽을 때만 쓰는 거야.

세 줄이 다 찍히면 다음으로 갈지 물어봐.

### 2단계 — 나이스에 개인결재선 저장하기 (내가 손으로 한다)

이건 네가 못 하는 일이야. 나한테 아래를 안내해주고, 다 했다고 할 때까지
기다려줘.

    결재선은 학교마다 사람마다 다르다. 누가 검토하고 누가 결재하는지를
    프로그램이 알 방법이 없다. 그래서 나이스에 「내 결재선」을 이름 붙여
    저장해 두고, 도구는 그 이름만 보고 골라 쓴다.

    1. 나이스에 로그인해 [복무] > [개인근무상황관리] 로 들어간다
    2. 조퇴를 하나 «작성만» 해본다 (아직 올리지 않는다)
    3. [승인요청] 을 누르면 기안문서상신 화면이 뜬다
    4. [개인결재선] 을 눌러 결재선을 만들고 «이름을 붙여» 저장한다
    5. 저장한 그 이름을 그대로 메모해 둔다. 3단계에서 쓴다

    ★ 이름은 짧게 짓는 게 편하다 — 조퇴 · 외출 · 지참
      「2026학년도 복무 결재선 (교감선생님)」처럼 길면 옮겨 적다가 틀린다

    ★ 글자가 한 자라도 다르면 못 찾는다. 띄어쓰기·쉼표·괄호까지 나이스에
      저장된 그대로여야 한다. 손으로 타이핑하지 말고 나이스 화면에서
      복사해 두는 편이 안전하다

    ★ 종류마다 결재선이 다르면 여러 개 저장해 둔다.
      조퇴는 A선, 출장은 B선인 학교가 많다

내가 이름을 메모했다고 하면 다음으로 가.


### 3단계 — 내 정보 설정

설정 마법사를 돌려줘.

    .\.venv\Scripts\python.exe -X utf8 setup_wizard.py

★ 이 명령을 네가 돌리면 «새 검은 창»이 따로 뜬다. 질문에는 내가 그 창에서 답한다.
  너는 입력을 대신 칠 수 없고, 쳐서도 안 돼 (특히 암호). 창이 닫힐 때까지 기다리면
  결과가 가려진 채로 너한테 돌아온다. 돌리기 «전에» 나한테 이렇게 말해줘 —

    곧 검은 창이 하나 새로 뜹니다. 작업표시줄에서 그 창을 눌러 질문에 답해 주세요.
    다 끝나면 Enter 를 눌러 창을 닫으시면 됩니다.

  ※ 창이 안 보이면 다른 창 뒤에 숨어 있는 거야. 작업표시줄의 검은 아이콘을 누르시라고 해줘
  ※ 네 쪽 명령이 시간 초과로 끝나도 창은 살아 있어. 창에서 끝내시게 하고,
    .\.venv\Scripts\python.exe -X utf8 show_config.py 로 들어갔는지만 봐 (가려서 나온다)

물어보는 항목이 뭘 뜻하는지 하나씩 설명해주고, 내가 답하면 그대로 넣어줘.
연락처랑 개인결재선 이름은 복무에 «꼭» 필요하니까 빠뜨리지 말고 물어봐.

  나이스 주소        서울이면 그냥 Enter. 다른 지역이면 지역 이름만 쳐도 된다 (예: 경기)
  학년 / 반          담임이 아니면 Enter
  인증서 이름        창에 «찾은 인증서 이름» 이 보이면 그냥 Enter (아래 참고)
  인증서 비밀번호    화면에 아무것도 안 보이는 게 정상. 그냥 치고 Enter
  연락처             복무에 꼭 필요. 010-1234-5678 형태
  개인결재선 이름    복무에 꼭 필요. 2단계에서 메모해 둔 이름
  휴업일 시트 ID     안 쓰면 Enter.
                    ID를 넣으면 «범위»(예: 출결!K2:K50)를 한 번 더 물어본다
  출결 자동화도?     ★ 복무만 쓸 거면 «n» 이라고 답한다

★★ 여기가 제일 많이 막히는 자리야. 잘 봐줘.

  마법사를 돌렸는데 «구글 로그인 창이 뜨거나» oauth_client.json 이
  없다는 말이 나오면, 그건 «출결 자동화용 구글 연동»이야.
  복무만 쓸 거면 그건 필요 없어. 그런데 옛 버전 마법사는 그걸 건너뛸 수가
  없어. 그러면 이렇게 해줘.

  (가) 먼저 최신으로 받아본다 —  git pull
      다시 돌려서 «출결 자동화도 쓰시겠습니까?» 질문이 나오면 n 이라고
      답하면 끝이야.

  (나) 그래도 구글을 요구하면, 마법사를 멈추고 설정 파일을 직접 만들어줘.
      아래 파일을 만들면 돼.

        %LOCALAPPDATA%\neis-automation\teacher_config.json

        {
          "neis_url": "https://sen.neis.go.kr/jsp/main.jsp",
          "grade": "",
          "class": "",
          "cert_name": "여기에 인증서 이름 그대로",
          "contact": "010-0000-0000",
          "approval_line": "2단계에서 메모한 결재선 이름",
          "calendars": {}
        }

      neis_url 은 내 지역 주소로 바꾸고, 담임이 아니면 grade·class 는
      비워 두면 돼. calendars 는 비어 있어도 통과해.

      이때는 인증서 비밀번호를 마법사가 안 물어보니까, 내가 검은 창에서
      직접 넣어야 해. 명령을 만들어서 나한테 줘.

        .\.venv\Scripts\python.exe -c "import keyring,getpass; keyring.set_password('neis-automation','인증서이름', getpass.getpass('인증서 암호: '))"

        .\.venv\Scripts\python.exe -c "import keyring; print('저장됨' if keyring.get_password('neis-automation','인증서이름') else '없음')"

      ★ 서비스 이름은 neis-automation 이야. 그리고 «venv 파이썬»으로
        돌려야 해. 그냥 python 으로 하면 keyring 이 없다고 나와.

☆ 인증서 이름 확인하는 법 — 나한테 이렇게 안내해줘.

    1. 브라우저로 본인 지역 나이스에 접속한다 (서울은 sen.neis.go.kr)
    2. [인증서 로그인] 을 누른다
       ※ 이것 하나다. 학부모서비스 · 학생서비스 · 아이디 로그인 ·
         간편인증 · 금융인증서 · 은행 공동인증서는 아니다
    3. 뜬 목록에서 내 인증서 줄에 적힌 글자를 그대로 메모한다.
       발급기관마다 모양이 다르다 —
       홍길동 · 홍길동0012345 · 홍길동(교육행정) 등
    4. 목록이 비어 있으면 이 컴퓨터에 인증서가 없는 것이다.
       평소 나이스가 되는 컴퓨터에서 해야 한다

☆ 인증서 비밀번호에 대해 나한테 이 네 가지를 꼭 말해줘.

    1. 이 일은 딱 한 번만 하면 된다. 그다음부터는 저절로 된다
    2. 암호는 대화창이 아니라 새로 뜬 검은 창에만 넣는다
    3. 암호를 칠 때 화면에 별표조차 안 보이는 게 정상이다. 고장이 아니다
    4. 저장되는 곳은 윈도우 [자격 증명 관리자] → [Windows 자격 증명] 이다.
       이 컴퓨터 안에만 있고 인터넷으로 나가지 않는다

★ 연락처와 결재선 이름 두 칸을 비우면 실행이 안 돼.
  "❌ 연락처가 없습니다" 또는 "❌ 개인결재선 프리셋 이름이 없습니다" 가
  뜨고 그냥 끝나. 고장이 아니라 값이 없다는 뜻이야.

설정이 끝나면 다음으로 갈지 물어봐.


### 4단계 — 연습. 화면만 채우고 승인요청은 안 누름

★ 처음에는 반드시 이걸 먼저 해. 결재선으로 올라가지 않으니 마음 놓고
  돌려봐도 돼.

먼저 나한테 물어봐 — 어떤 복무를(조퇴·외출·지각), 며칠, 몇 시부터 몇 시까지,
사유가 뭔지.

내가 답하면 이렇게 돌려줘. 맨 뒤 --dry-run 이 「연습」이라는 뜻이야.

    .\.venv\Scripts\python.exe main_bokmu.py --type 조퇴 --date 2026-09-10 --start 15:00 --end 16:20 --reason "개인 사유" --dry-run

크롬이 열려서 신청서까지 채운 뒤 거기서 멈춰.
채워진 화면은 bokmu_form_filled.png 라는 그림 파일로도 저장돼.
그 그림을 나한테 보여주고, 각 칸에 뭐가 들어갔는지 글로도 알려줘.

☆ 각 칸이 뜻하는 것 (내가 물어보면 설명해줘)

    --type            조퇴 · 외출 · 지각 셋 중 하나. 다른 말은 안 받는다
    --date            날짜. 2026-09-10 형태
    --start           시작 시각. 15:00 형태
    --end             종료 시각. 16:20 형태
    --reason          사유·용무. 띄어쓰기가 있으면 따옴표로 감싼다
    --contact         연락처. 설정에 넣어 뒀으면 안 써도 된다
    --approval-line   이번만 다른 결재선을 쓸 때 붙인다
    --dry-run         화면만 채우고 승인요청은 안 누른다

★ 분은 5분 단위로 맞춰져. 나이스 시각 선택칸이 5분 단위라 15:03 처럼
  적으면 가장 가까운 5분으로 바뀌어.

★ 도는 동안 크롬 창을 건드리면 안 돼. 나한테 그 말을 꼭 해줘.
  다른 데를 누르거나 창을 닫으면 중간에 멈춰.

내가 화면을 보고 "맞다" 고 할 때까지 5단계로 넘어가지 마.


### 5단계 — 진짜로 상신하기

내가 "화면 확인했어, 진짜로 올려줘" 라고 하면 그때 --dry-run 만 빼고
똑같이 돌려줘.

    .\.venv\Scripts\python.exe main_bokmu.py --type 조퇴 --date 2026-09-10 --start 15:00 --end 16:20 --reason "개인 사유"

"🎉 결재선 지정 + 상신 완료!" 가 뜨고 브라우저는 15초 뒤에 저절로 닫혀.

★ 이번만 다른 결재선으로 올릴 때는 --approval-line "출장" 처럼 붙이면 돼.

★ 오류가 나면 브라우저를 «열어둔 채로» 기다려. 화면을 보고 어디서 멈췄는지
  확인할 수 있어. 그 화면을 나한테 보여줘.

★ 상신 직전 확인창이 «예상과 다르면» 도구가 스스로 멈추고 나한테 넘겨.
  이런 줄이 뜨면 자동으로 누르지 않은 거야.

    ⛔  예상과 다른 확인창입니다. 화면을 보고 직접 눌러 주세요.
        기대한 확인창: ...
        실제 확인창 내용: ...
        브라우저는 열어 둡니다. 화면에서 직접 처리하신 뒤 Enter를 누르세요.

  ⛔ 뒤의 말은 상황마다 달라 — 「확인창이 2개 겹쳐 떠 있습니다」,
  「이미 지난 단계의 확인창이 다시 떴습니다」 처럼 나올 수도 있어.

  도구가 «그냥 넘어가도 되는» 창으로 아는 건 딱 둘뿐이야.
    ① 알림 — 최종 결재자 이외의 결재자는 검토로 변경합니다
    ② 확인 — 상신하겠습니까?
  그 밖의 창(예: 「중복 신청입니다. 그래도 상신하겠습니까?」)이 뜨면
  누르지 않고 멈춰. 화면을 나한테 그대로 읽어주고, 올릴지 말지는 내가 정해.

★ ⛔ 로 멈춘 뒤 Enter 를 눌러도 «자동으로 이어서 올리지는 않아». 그 실행은
  거기서 끝나고, 상신 여부는 내가 화면에서 확인해야 해. 그렇게 알려줘.


### 6단계 — 올라간 문서를 눈으로 확인하기

★ 이걸 꼭 하라고 나한테 말해줘.

    몇 시간짜리 조퇴인데 «일수가 1일 2시간 30분» 으로 들어갈 때가 있다.
    나이스가 1일을 자동으로 붙여 버리는 것이다.
    상신된 문서를 열어 확인하고, 그렇게 들어갔으면 1일을 지운다.

    이 도구는 입력을 대신할 뿐 판단하지 않는다.
    올린 뒤에는 나이스 화면에서 눈으로 확인한다.

여기까지 되면 앞으로는 내가 이렇게만 말해도 되게 해줘.

    오늘 3시부터 4시 20분까지 병원 가야 해서 조퇴 올려줘

네가 오늘 날짜와 시각을 알아서 채워 넣고, 내가 "연습으로" 라고 덧붙이면
올리지 않고 화면만 채워.


## 7. 막혔을 때

  python 은(는) 내부 또는 외부 명령이 아닙니다
      설치가 끝난 뒤라면 그냥 python 말고 .\.venv\Scripts\python.exe 를 써.
      setup.ps1 도중에 나왔다면 클로드 앱을 완전히 껐다 켜고 setup.ps1 을
      한 번 더 돌려. 그래도 나오면 파이썬이 깔렸는지, 어디에 있는지 네가
      직접 확인해서 원인을 쉬운 말로 알려주고, 원인에 맞게 고쳐줘

  이 시스템에서 스크립트를 실행할 수 없으므로
      실행 정책 때문에 막힌 거야. 그걸 풀고 다시 해

  .\setup.ps1 : 용어를 인식할 수 없습니다
      폴더 위치가 달라. 키트 폴더로 옮겨서 다시 해

  ModuleNotFoundError: No module named 'playwright'
      크롬 제어 도구가 안 깔린 거야. playwright 를 깔아

  Executable doesn't exist
      playwright 가 쓸 브라우저를 아직 안 받은 거야. 그것까지 받아

  python 을 쳤더니 Microsoft Store 창이 열린다
      윈도우가 넣어 둔 가짜 python 이야. 진짜 파이썬을 깔아

  설치가 계속 실패한다
      학교망 방화벽일 수 있어. 개인 인터넷(테더링 등)에서 설치만 한 번 해보자

  ❌ 연락처가 없습니다 / ❌ 개인결재선 프리셋 이름이 없습니다
      3단계 설정에 그 값이 비어 있는 거야. 설정을 다시 돌려서 채워

  인증서 창은 뜨는데 자동 선택이 안 된다
      설정의 인증서 이름이 실제와 달라. 한 글자만 달라도 못 찾아.
      나이스 목록에 뜨는 글자를 그대로 다시 넣자

  인증서 비밀번호를 찾을 수 없습니다
      자격 증명 관리자에 저장이 안 된 거야. 3단계 마지막 부분을 다시 하자

  비밀번호는 들어가는데 로그인이 안 된다
      인증서 만료를 의심해. 나이스에 손으로 로그인해 보고,
      거기서도 안 되면 인증서 문제야

  크롬이 안 열린다 / channel="chrome" 오류
      구글 크롬이 이 컴퓨터에 없는 거야. 엣지·웨일로는 안 돼

  「중복로그인이 발생하여 로그아웃 처리되었습니다」
      평소 쓰는 크롬이 같은 계정으로 켜져 있어서 서로 세션을 뺏은 거야.
      평소 창에서 로그아웃하시라고 나한테 말해주고, 그다음 다시 해

  학교 밖이라 나이스가 아예 안 열린다
      docs/지시서/0_학교밖-EVPN.md 로 준비하고, 명령을 run_vpn.py 로 감싸서 다시 해

  결재선 목록에서 내 프리셋을 못 찾는다
      나이스에 저장된 이름과 글자가 정확히 같아야 해.
      띄어쓰기·쉼표·괄호까지 확인하자

  연락처 칸이 깨진다
      특수한 입력칸이라 그래. 지우고 천천히 다시 넣어

  중간에 멈추고 크롬이 열려 있다
      나이스 화면 구조가 바뀌었을 수 있어. 어디서 멈췄는지 화면을 보고
      나한테 알려줘

그래도 안 되면 어디서 멈췄는지 화면을 보여주고, 빨간 글씨 전체를 그대로
적어줘. 저장소에 물어볼 수도 있어 —
https://github.com/workcalmkite-hue/neis-automation-kit/issues

★ 화면 사진을 올릴 때는 이름·연락처가 찍히지 않았는지 꼭 확인하라고
  나한테 말해줘. 나이스 복무 화면에는 결재자 이름이 그대로 나와.


## 8. 마지막으로

지금까지 읽은 걸 아래 형식으로 짧게 요약해서 나한테 보여줘.

  - 오늘 뭘 하는 건지 한 줄
  - 오늘 어디까지 가는지 (몇 단계까지, 뭘 안 하는지)
  - 네가 절대 안 할 것 세 가지

그러고 나서 "1단계부터 시작할까요?" 하고 물어봐.
내가 좋다고 하면 그때 시작해.
