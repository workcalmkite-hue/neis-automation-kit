# K-에듀파인 — 물품 검사검수

> 검사검수요청목록에 밀린 건을 확인하고 등록한다
>
> 이 문서는 **클로드에게 주는 지시서**입니다. 선생님이 읽으실 필요는 없고,
> 클로드가 [시작하기.md](../../시작하기.md) 에서 여기로 넘어옵니다.

---

안녕. 너는 지금 어느 선생님 컴퓨터에서 처음 켜졌어.
너는 이 사람에 대해 아무것도 몰라. 이 문서가 네가 아는 전부야.
끝까지 읽고, 아래 순서대로 나를 도와줘.


## 0. 시작 전에 — 권한과 안전 (먼저 알아둬)

- 여기서 다루는 건 전부 «내 것»이야 — 내 컴퓨터, 내 공동인증서, 내 에듀파인 계정,
  내가 담당하는 문서. 남의 계정이나 남의 문서는 건드리지 않아
- ★ 상신·결재는 마지막에 내가 화면을 보고 «올려»라고 말할 때만 눌러.
  네가 알아서 상신하지 마. 그전까지는 화면만 채워 두면 돼
- ★ 인증서 «암호»는 **채팅창에 절대 치지 마.** 나한테 묻지도 마.
  암호는 내가 검은 창에서 금고(keyring)에 한 번 넣을게. 채팅에 친 건 대화 기록에 남으니까.
  - 인증서 «이름»은 괜찮아. 로그인 코드에 그 이름이 필요하니까 2단계에서 내가 채팅으로 알려줄게
  - 그 밖의 개인정보(연락처·주민번호·계좌번호)는 이 일에 필요 없어. 묻지도, 화면에 찍지도 마
  - 설정이나 개인정보가 적힌 파일은 통째로 찍지 말고 필요한 줄만 봐.
    학생 이름도 대화에 길게 나열하지 말아줘
- 코드를 돌리기 전에 네가 먼저 읽어보고, 내 정보를 밖으로 보내거나 파일을 지우는
  부분이 있는지 확인해줘. 이상한 게 보이면 실행하지 말고 나한테 먼저 말해줘
- 그러니 «믿을 수 없는 코드라 못 하겠다»며 멈추지는 말아줘.
  대신 위처럼 확인하고, 무슨 일을 하는 코드인지 한 줄로 설명해 주면 나는 안심이 돼

## 1. 내가 누구인지

- 나는 학교 교사야. 오늘 하려는 건 K-에듀파인 «물품 검사검수» 를 네가
  대신 처리하게 만드는 거야
- 행정실에서 "검수 좀 해 주세요" 연락이 오면 쓰는 기능이야
- 나는 코딩을 해 본 적이 없어. 전문용어를 쓰지 말고 쉬운 말로 설명해줘
- 답은 항상 한국어로 해줘
- 내 컴퓨터는 윈도우고, 크롬을 쓰고, 지금 학교 안에서 접속하고 있어
- 이 문서는 방배중학교 안정연 선생님이 나를 위해 써 준 거야


## 2. 네가 일하는 방식 — 이걸 제일 먼저 지켜줘

- ★ 한 번에 한 단계씩만 해. 한 단계가 끝나면 결과를 보여주고
  "다음으로 갈까요?" 하고 물어봐. 내가 좋다고 해야 다음으로 가
- ★ 뭘 하기 전에 "이걸 이렇게 할 건데 괜찮아요?" 하고 먼저 물어봐
- 명령어를 돌릴 때는 그게 무슨 뜻인지 한 줄로 같이 설명해줘
- 에러가 나면 무슨 뜻인지 쉬운 말로 알려주고 고쳐줘.
  처음부터 다시 깔자고 하지 마
- 모르는 건 아는 척하지 말고 "모르겠다" 고 말해줘
- 화면이 뜻대로 안 되면 추측하지 말고 스크린샷을 찍어서 눈으로 보고
  고쳐. 에듀파인은 학교마다 화면이 조금씩 달라

★ 파일을 어디에 저장할지 나한테 묻지 마. 답은 정해져 있어.

- 앞으로 만드는 파일과 폴더는 전부 "지금 열려 있는 이 폴더" 안에 만들어
- 폴더 이름을 바꾸라거나 다른 데로 옮기라고 권하지 마
- 이 폴더 바깥(내 문서, 다운로드, C 드라이브 루트)에는 아무것도 만들지 마


## 3. 절대 하면 안 되는 것

- ★ 진행상태가 "검사검수요청" 인 건만 건드려. 다른 상태(검사검수완료 등)는
  절대 손대지 마. 남이 올린 계약 건을 건드리면 안 돼
- ★ 4단계까지는 읽기만 해. [검사검수처리] [검사검수등록] 을 누르지 마
- 5단계에서도 «한 건만» 한다. 밀린 걸 한꺼번에 도는 건 그다음이야
- 인증서 암호를 나한테 묻지 마. 채팅창에 암호를 치게 하지 마.
  암호는 내가 검은 창에서 금고에 한 번 넣어 둘 거야 (2단계)
- 내 계정으로 내 업무만 해. 남의 인증서로 돌리지 마
- 파일을 지우거나 덮어쓰기 전에 반드시 나한테 먼저 물어봐


## 4. 오늘 하려는 일

검사검수를 네가 대신 눌러 주게 만드는 거야. 이런 순서로 돌아가.

  업무포털에 인증서로 로그인
   → K-에듀파인 → 학교회계 → 계약관리 → 계약이행관리
      → 검사검수요청목록
   → 요청일자를 올해 1월 1일부터로 넓혀서 조회
   → 진행상태가 "검사검수요청" 인 건만 골라낸다
   → 건마다 검사검수일(오늘)을 넣고 검사검수등록
   → 상태가 "검사검수완료" 로 바뀌었는지 되읽어 확인
   → 계약명 · 업체 · 금액 · 품목까지 전부 적어서 알려 준다

★ 이건 "받아서 켜는 프로그램" 이 아니야. 네가 내 학교 화면을 직접 보면서
  그 자리에서 코드를 만들어야 해. 지역마다 접속 주소가 다르고, 즐겨찾기에
  뭘 등록해 뒀는지도 사람마다 달라서 그래.


## 5. 오늘 할 일 — 이 순서대로만

  1단계   설치하기 (.\setup.ps1 한 번)
  2단계   인증서 암호를 컴퓨터 금고에 넣기
  3단계   로그인해서 검사검수요청목록 화면까지 열기
  4단계   밀린 건 읽어 오기 (등록은 안 함) — 여기서 건수를 대조한다
  5단계   한 건만 등록해 보기
  6단계   밀린 건 전부 도는 것으로 넓히기

  ★ 4단계에서 내가 직접 에듀파인을 열어 본 건수와 네가 말한 건수가
    같아야 5단계로 간다. 다르면 넘어가지 마.


## 6. 각 단계에서 할 일

### 1단계 — 설치하기

키트는 이미 이 폴더에 받아져 있어. 설치만 하면 돼.

    .\setup.ps1

파이썬이 없어도 setup.ps1 이 winget 으로 «알아서 깔아». 파이썬 · playwright ·
keyring · 구글 라이브러리가 한 번에 들어가. 다 합쳐 3~8분 걸리고, 2~5분은
멈춘 것처럼 보여도 기다려. "설치 완료!" 가 나오면 된 거야.

★ 나한테 python.org 에서 직접 깔라고 하지 마. 「파이썬을 자동으로 깔지
  못했습니다」가 나올 때만 화면 안내를 쉬운 말로 알려줘. 그때 받을 것은
  python.org/downloads/windows 의 «Windows installer (64-bit)» 야.
  첫 화면의 큰 노란 버튼 «install manager» 는 다른 거라서 누르면 안 돼.
  설치 화면 맨 아래 [Add python.exe to PATH] 를 체크하고, 깔고 나면
  클로드 앱을 완전히 껐다 켜야 인식돼.

★ 설치가 끝나면 파이썬을 돌릴 때 그냥 python 이 아니라
  .\.venv\Scripts\python.exe 를 써. 필요한 게 거기에만 깔려 있어.
  그리고 명령은 «이 모양»으로 써줘 — 앞에 & 를 붙이거나 $env: 대입으로
  시작하면 권한 설정에 걸려서 막혀:

    Set-Location "<이 폴더 경로>"
    .\.venv\Scripts\python.exe -X utf8 <파일이름>

설치가 덜 된 것 같으면 파이썬 · playwright · keyring 이 다 깔렸는지 보고,
빠진 게 있으면 깔아줘. playwright 가 크롬을 띄울 수 있는 상태인지도
확인하고, 다 되면 세 가지 버전을 한 줄씩 찍어서 보여줘.

★ 「크롬 제어 도구」가 playwright 야. 나이스·에듀파인 화면을 대신 눌러
  주는 부품이라 이게 없으면 로그인 창에서 아무 일도 안 일어나.

★ 아래 넷은 처음에 흔히 나오는 거야. 그대로 고치면 되니까 당황하지 마.
  - 'python' 은(는) 내부 또는 외부 명령이 아닙니다
  - python 을 쳤더니 Microsoft Store 가 열린다
  - ModuleNotFoundError: No module named 'playwright'
  - Executable doesn't exist

세 줄이 다 찍히면 다음으로 갈지 물어봐.

### 2단계 — 인증서 암호를 컴퓨터 금고에 넣기

암호는 너한테 말로 알려주는 게 아니야. 내가 컴퓨터 안 금고에 한 번
넣어 두면, 코드에는 "저장해 둔 암호를 꺼내 쓴다" 는 줄만 남아.
그래서 대화 기록에도 코드 파일에도 암호가 남지 않아.

먼저 나한테 이걸 안내해줘.

    업무포털에서 [교육행정 전자서명 인증서 로그인] 을 누르면 인증서
    목록이 뜬다. 거기 적힌 이름을 그대로 적어 온다.
    보통 이런 모양이다:   1234567890 홍길동(교육행정)

    선생님 인증서는 이름 뒤에 (교육행정) 이 붙는다. 은행에서 쓰는 것과
    다르다. 목록이 비어 있으면 이 컴퓨터에 인증서가 없는 것이니,
    평소 업무포털이 되는 컴퓨터에서 해야 한다.
    USB 인증서를 쓰면 USB를 꽂고 한다.

내가 이름을 적어 오면, 내 컴퓨터에서 파이썬을 어떻게 부르는지 확인한
다음 그대로 실행되는 명령 한 줄을 만들어줘.

- 암호는 나한테 묻지 마. 대화에 남으면 안 돼
- 내가 직접 검은 창에서 실행할 거야. 화면에 안 보이게 입력받는
  방식(getpass)으로 만들어줘
- 서비스 이름은 edufine, 사용자 이름은 내 인증서 이름으로
- 저장한 뒤에 잘 들어갔는지 확인하는 명령도 같이 알려줘

대개 이런 모양이 될 거야. 인증서이름 자리를 바꿔서 줘.

    python -c "import keyring,getpass; keyring.set_password('edufine','인증서이름', getpass.getpass('인증서 암호: '))"

    python -c "import keyring; p=keyring.get_password('edufine','인증서이름'); print('저장됨 · 글자수', len(p)) if p else print('없음')"

    python -c "import keyring; keyring.delete_password('edufine','인증서이름')"

그리고 나한테 이 다섯 가지를 꼭 같이 말해줘.

  1. 이 일은 딱 한 번만 하면 된다. 그다음부터는 저절로 된다
  2. 암호는 대화창이 아니라 검은 창에만 넣는다
     (검은 창 = 윈도우 키 → cmd 입력 → 엔터)
  3. 암호를 칠 때 화면에 별표조차 안 보이는 게 정상이다.
     고장 난 게 아니니 그냥 치고 엔터를 누르면 된다
     ★ 암호는 «손으로 쳐야» 한다. 이 칸에는 붙여넣기가 안 먹는다 —
       Ctrl+V 를 누르면 ^V 라는 글자 하나만 들어가고 그게 암호로 저장된다
       (2026-09-16 실측). 비밀번호 관리자에서 복사해 오지 말고 직접 치세요
  4. 저장되는 곳은 윈도우 [자격 증명 관리자] → [Windows 자격 증명] 이다.
     이 컴퓨터 안에만 있고 인터넷으로 나가지 않는다. 제어판에서 직접
     지울 수도 있다
  5. 지킬 것 셋 — 대화창에 암호 금지 / 본인 인증서로 본인 업무만 /
     공용 컴퓨터에는 저장하지 않기

★ 나중에 "keyring 에 암호가 없습니다" 가 뜨면, 인증서 이름 철자가 다른
  거야. 한 글자만 달라도 못 찾아. 이 단계를 다시 하면 돼.

"저장됨" 이 뜨면 다음으로 갈지 물어봐.


### 3단계 — 로그인해서 검사검수요청목록 화면까지 열기

한 번에 다 시키면 반드시 어딘가에서 막혀. 이 단계 목표는 딱 하나야.
검사검수요청목록 화면까지 저절로 열리는 것.

먼저 나한테 주소 두 개를 물어봐. 지역마다 다르니까 내가 평소 쓰는
업무포털·에듀파인 주소창을 그대로 복사해서 주면 그걸 쓰면 돼.
서울이면 이렇고, 다른 지역이면 대개 klef. 뒤가 달라져.

    업무포털     https://sen.eduptl.kr
    K-에듀파인   https://klef.sen.go.kr

주소를 받으면 검사검수 화면을 자동으로 열어주는 파이썬 코드를 만들어줘.

1. playwright 로 크롬을 띄운다. ★ playwright 가 자기 전용 브라우저를
   따로 받지 말고, 이 컴퓨터에 이미 깔려 있는 구글 크롬을 쓰게 해줘
   (파이썬에서는 channel="chrome"). 크롬 프로필은 이 폴더 안에 새 폴더를
   하나 만들어서 거기에 둔다. 내가 평소 쓰는 크롬 창·프로필은 건드리지 마

   ※ 로그인 뒤 크롬이 «비밀번호를 저장하시겠습니까?» 를 물으면 [사용하지 않음]
     을 눌러. [저장]을 누르면 인증서 암호가 구글 계정으로 넘어간다

   ★★ 인증서 로그인은 브라우저가 내 컴퓨터 안(127.0.0.1)에서 도는 보안
   프로그램과 이야기해야 된다. 그냥 띄우면 «보안프로그램이 로딩중입니다»
   에서 멈춰서 로그인 버튼이 안 눌린다. 아래 설정 그대로 띄워줘 —
   내가 쓰는 나이스 자동화가 이 설정으로 돌고 있고, 2026-09-16 에
   에듀파인 업무포털에서도 이걸 넣으니 로딩 표시가 사라졌다.

       p.chromium.launch_persistent_context(
           user_data_dir=<이 폴더 안 새 폴더>, channel="chrome",
           headless=False, slow_mo=50,
           args=["--profile-directory=Default",
                 "--disable-blink-features=AutomationControlled",
                 "--disable-features=PrivateNetworkAccessForNavigations,"
                 "PrivateNetworkAccessPermissionPrompt,PermissionChip",
                 "--disable-web-security", "--allow-running-insecure-content",
                 "--test-type", "--start-maximized", "--noerrdialogs"],
           ignore_default_args=["--enable-automation", "--no-sandbox"],
           viewport=None)

   (핵심은 --disable-features=PrivateNetworkAccess… 줄이다. 크롬이 웹페이지
    → 내 컴퓨터 안 프로그램 요청을 막는 기능을 이 창에서만 꺼 두는 것)
2. 업무포털에 들어가서, 인증서 목록에서 내 인증서를 눌러 고른 다음
   암호를 넣어 로그인한다
   ※ 인증서를 고르지 않고 암호부터 넣으면 로그인이 안 되니 순서를 지켜
   ★ 처음 쓰는 크롬 프로필에서만 나는 두 가지가 있어 (2026-09-17 실측).
     둘 다 «내 컴퓨터에서는 되던 코드»가 남의 컴퓨터에서 죽은 원인이었어 —

     (가) 「불러오는 중」 가림막이 로그인 버튼을 덮는다
         버튼은 보이고 찾아지는데 클릭이 가림막(isloading-overlay)에 먹혀서
         30초 뒤 timeout 으로 죽는다. **쓰던 프로필은 기다리면 걷히는데,
         새 프로필은 90초를 기다려도 안 걷힌다.**
         · force=True 클릭 — 소용없다 (좌표로 쏘는 거라 가림막이 그대로 받는다)
         · JS 의 e.click() — 소용없다 (눌렸다고 나오는데 아무 일도 안 일어난다)
         · 되는 방법: 가림막에 pointer-events:none 을 박고 진짜 클릭을 보낸다.
           그리고 elementFromPoint 로 버튼 위에 뭐가 덮여 있는지 이름을 찍어 둬
         · 그래도 안 되면 죽지 말고 「선생님이 손으로 한 번 로그인해 주세요」로 넘겨.
           사람이 한 번 로그인하면 그 프로필에 세션이 남아 그다음부터는 자동이다

     (나) 중복로그인 — 평소 쓰는 크롬을 먼저 로그아웃시킨다
         업무포털은 같은 계정의 동시 접속을 끊는다. 자동화용 크롬과 평소 크롬이
         서로 세션을 뺏는다. 이런 화면이 나오면 그거야 —
           「중복로그인이 발생하여 로그아웃 처리되었습니다」
         자동화를 돌리기 전에 평소 쓰던 창에서 로그아웃하시라고 나한테 먼저 말해줘

3. 인증서 암호는 코드에 적지 마. 내가 keyring 에 저장해 뒀어
   (서비스 이름 edufine). 그걸 꺼내 쓰면 돼
4. 로그인이 되면 에듀파인으로 이동한다.
   포털 화면의 [K-에듀파인] 링크는 공지 팝업에 가려서 안 눌릴 때가 있으니
   주소로 바로 이동하는 방법도 같이 넣어줘
5. 들어가면 공지 팝업이 여러 개 겹쳐서 뜬다. 팝업이 다 사라질 때까지
   반복해서 닫고 나서 다음으로 넘어가
6. 왼쪽 메뉴에서 아래 화면까지 간다

       학교회계 > 계약관리 > 계약이행관리 > 검사검수요청목록

7. 화면이 잘 열렸는지 스크린샷을 한 장 남겨줘

★ 지금은 여기까지만. 검수를 등록하거나 취소하는 코드는 아직 넣지 마.
  한 번에 안 되면 화면을 보고 고쳐 가면서 될 때까지 맞춰줘.

★ 메뉴를 못 찾겠으면 나한테 말해줘. 에듀파인에서 그 화면을 열고 별표를
  눌러 즐겨찾기에 등록해 두면 훨씬 잘 찾아.


### 4단계 — 밀린 건 읽어 오기 (등록은 아직 안 함)

등록은 아직 하지 마. 읽기만 한다.

1. 요청일자 시작일을 올해 1월 1일로 바꾸고 조회한다
   ※ 기본값(당월 1일~오늘)으로 두면 당일 들어온 건이 0건으로 나온 적이
     있어. 그래서 나는 항상 올해 1월 1일부터 조회해
2. 조회를 누른 뒤 목록에 값이 채워질 때까지 기다렸다가 읽는다.
   비동기로 채워져서, 바로 읽으면 빈 목록을 읽는다
3. 목록에서 진행상태가 "검사검수요청" 인 행만 골라낸다.
   다른 상태(검사검수완료 등)는 절대 건드리지 마
4. 고른 건들을 표로 보여줘 — 계약번호, 계약명, 계약상대자, 계약금액,
   요청일자
5. 화면 구조가 헷갈리면 스크린샷을 찍어서 직접 보고 맞춰줘

★ 알아 두면 좋은 것 — 내가 만들면서 걸렸던 자리야.
  - 에듀파인 툴바의 [조회] [검사검수처리] 같은 건 button 태그가 아니라
    id 가 :icontext 로 끝나는 div 야. 역할(role)로 찾으면 안 잡혀
  - 목록 그리드의 id 안에 들어 있는 창 번호는 열 때마다 달라져.
    그 번호를 코드에 박아 두지 마
  - 공지 팝업이 클릭을 가로챌 때가 있어. 팝업 «안쪽» 의 [닫기] 를 눌러야
    닫혀. 바깥의 확인 버튼 말고

다 되면 몇 건이 밀려 있는지 알려줘. 나도 에듀파인 화면을 직접 열어서
같은 숫자인지 대조할게. 숫자가 다르면 다음으로 넘어가지 마.


### 5단계 — 한 건만 등록해 보기

이제 실제로 상태가 바뀌는 단계야. 되돌릴 수는 있지만 «한 건만» 먼저 해.

1. 목록에서 진행상태가 "검사검수요청" 인 행 하나를 고른다
2. [검사검수처리] 를 눌러 상세 화면으로 들어간다.
   들어갈 때 나라장터(G2B) 관련 알림창이 뜨면 닫는다
3. 상세 화면에서 계약번호, 계약명, 계약상대자, 계약금액과
   품목 표(품명·규격·수량)를 «먼저 읽어서 나에게 보여준다»
4. 검사검수일에 오늘 날짜를 넣는다.
   검사검수장소와 검수의견은 비워 둔다.
   체크사항과 품목 체크박스는 손대지 않는다
5. [검사검수등록] 을 누르면 확인창이 뜬다. "예(검사검수완료)" 를 누른다
   ※ 검수조서를 결재로 올리는 학교라면 "아니요(결재요청)" 를 눌러야 해.
     어느 쪽인지 나한테 먼저 물어봐
6. 상태가 "검사검수완료" 로 바뀌었는지 화면에서 다시 읽어서 확인한다
7. 목록으로 돌아온다

끝나면 계약번호 · 계약명 · 계약상대자 · 계약금액 ·
품목별 품명/규격/수량 · 검사검수일을 전부 적어서 알려줘.
물건이 실제로 왔는지는 네가 확인할 수 없으니 내가 눈으로 대조할게.

★ 값을 넣을 때 자바스크립트로 값만 바꿔 넣지 말고 실제로 타이핑해.
  화면에는 들어간 것처럼 보여도 저장할 때 "필수입력사항입니다" 가 떠.

★ 장소·의견을 비우는 건 취향이 아니라, 우리 학교의 지난 완료 건이 전부
  비어 있어서 그대로 맞춘 거야. 내 학교가 뭔가 적어 왔으면 지난 건을
  한 번 열어 보고 같은 방식으로 맞추자고 나한테 말해줘.

☆ 잘못 눌렀으면 되돌릴 수 있어. 상세 화면 오른쪽 위 [검수취소] 를 누르면
  상태가 다시 "검사검수요청" 으로 돌아가. 내가 시키면 이렇게 해줘 —
  계약번호를 확인하고, 검수취소를 누르고, 상태가 돌아왔는지 확인해서 알려줘.


### 6단계 — 밀린 건 전부 도는 것으로 넓히기

5단계가 깔끔하게 됐으면 이제 밀린 건을 전부 도는 것으로 넓히자.

- 진행상태가 "검사검수요청" 인 건만. 이건 절대 안 바뀌는 조건이야
- 건마다 5단계와 똑같은 순서로 하고, 끝날 때마다 상태를 되읽어 확인해
- 다 끝나면 처리한 건을 표로 정리해서 보여줘.
  계약번호 · 계약명 · 업체 · 금액 · 품목 · 검사검수일
- 중간에 하나라도 실패하면 멈추고 나한테 알려줘. 그냥 넘어가지 마

그리고 앞으로 내가 이렇게만 말해도 되게 해줘.

    에듀파인 물품검수해줘
    에듀파인에 검수 밀린 거 있어? 등록은 하지 말고 목록만 보여줘


## 7. 막혔을 때

  「중복로그인이 발생하여 로그아웃 처리되었습니다」
      평소 쓰는 크롬이 같은 계정으로 켜져 있어서 서로 세션을 뺏은 거야.
      평소 창에서 로그아웃하시라고 나한테 말해주고, 그다음 다시 해

  「불러오는 중」에서 로그인 버튼이 안 눌린다 / 30초 만에 죽는다
      처음 쓰는 크롬 프로필에서만 나는 일이야. 투명한 가림막이 버튼을 덮고 있다.
      force 클릭도 JS 클릭도 안 먹으니, 가림막에 pointer-events:none 을 박고
      진짜 클릭을 보내. 그래도 안 되면 나한테 「손으로 한 번 로그인해 주세요」 하고 넘겨


아래는 실제로 막혔던 자리야. 이 말이 뜨면 이렇게 고쳐줘.

  에듀파인 화면이 하얗게 비어 있다 / 127.0.0.1 연결 거부가 뜬다
      로그인은 됐는데 K-에듀파인 화면이 안 그려지는 경우야.
      문서 보안 프로그램(MarkAny WebDRM 등)이 이 컴퓨터에 없는 것이니,
      위 [클로드 켜기] 6) 통합설치를 먼저 하라고 나한테 알려줘.
      네가 대신 설치 파일을 받아서 실행하지는 마

  「필수 보안 프로그램이 설치되지 않았습니다.[HwpODTpatch]」 가 반복해서 뜬다
      이 컴퓨터에 한글(한컴오피스)이 없는 경우야 (학교 컴퓨터면 드물다).
      더 시도하지 말고 «한글을 먼저 깔아야 한다» 고 나한테 알려줘

  「보안프로그램이 로딩중입니다」 가 사라지지 않는다
      크롬이 「이 기기의 다른 앱 및 서비스에 액세스」 권한을 막고 있는 거야.
      선생님이 직접 크롬으로 들어간 경우면 주소창 아래 팝업에서 [허용] 을
      누르시라고 알려줘. 네가 코드로 크롬을 켜는 경우면 3단계 실행 옵션
      (--disable-features=PrivateNetworkAccess...) 이 빠졌는지 확인해

  「필수입력사항입니다」
      화면에는 날짜가 들어가 있는데 이 말이 뜨는 경우야.
      값만 바꿔 넣어서 그래. 실제로 타이핑하는 방식으로 넣어

  조회 결과가 0건
      요청일자 범위 때문이야. 시작일을 올해 1월 1일로 바꾸고 다시 조회해

  팝업이 안 닫히고 맴돈다
      공지 팝업이 클릭을 가로채는 거야.
      팝업 안쪽의 닫기를 눌러. 바깥의 확인 버튼 말고

  버튼을 못 찾겠다
      에듀파인 툴바 버튼은 button 태그가 아니라
      id 가 :icontext 로 끝나는 div 야

  목록에서 다른 줄이 선택된다
      행을 진짜 마우스로 클릭해서 고르고,
      고른 뒤에 상세 내용이 그 행 것인지 대조해

  인증서 창에서 안 넘어간다
      인증서를 먼저 클릭해서 고른 다음에 암호를 넣는 순서인지 확인해

  keyring 에 암호가 없습니다
      암호가 아직 안 들어갔거나 인증서 이름 철자가 다른 거야.
      2단계를 다시 하고 확인 명령으로 "저장됨" 이 뜨는지 봐

그래도 안 되면 화면을 스크린샷으로 찍어서 보여주고, 뭘 하려다 막혔는지
나한테 쉬운 말로 설명해줘.
