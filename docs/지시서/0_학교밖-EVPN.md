# 학교 밖(EVPN) 준비 — 처음 한 번만

> 집·연수장처럼 **학교 밖**에서 나이스·에듀파인을 쓰려면 EVPN(원격업무지원)으로 붙어야 한다.
> 이 문서는 그 준비를 한 번 끝내는 **클로드용 지시서**다. 선생님이 읽으실 필요는 없다.
>
> **언제 읽나:** 고른 지시서(1~4)의 **설정 마법사 단계를 끝낸 직후**, 나이스·업무포털에 처음 들어가기 전.
> 끝나면 원래 지시서로 돌아가서 이어 간다.

---

## 0. 먼저 알아둘 것

- **서울(evpn.sen.go.kr · AXGATE VPN Client)만 시험했다.** 선생님이 서울이 아니면
  «아직 시험 안 된 지역이라 안 될 수 있다» 고 **먼저** 말하고, 그래도 해 볼지 여쭤봐
- ★ **EVPN 비밀번호·인증서 암호를 채팅창에 치게 하지 마.** 묻지도 마.
  아이디는 괜찮다. 비밀번호가 필요하면 `evpn.py password` 가 **새 검은 창**을 띄우고, 선생님이 그 창에만 친다
- ★ AXGATE 의 2차 인증·«이미 접속 중» 창은 도우미가 처리한다. **그 창을 네가 누르려고 하지 마**
- AXGATE 가 깔렸는지 보려고 **C:\ 전체를 뒤지거나 `Win32_Product` 를 부르지 마.** 몇 분씩 걸린다.
  아래 1단계 명령 한 번이면 설치·도우미·아이디·연결 상태가 다 나온다
- 명령은 전부 **`.venv` 파이썬**으로, 한 줄로 돌린다 (앞에 `cd`·`$env:`·`&` 를 붙이지 않는다)
- 부산·전남·강원·경기 등은 **VPN 이 붙어 있는 동안 인터넷이 막혀 너도 응답을 못 받는다.**
  그래서 연결은 늘 `run_vpn.py` 한 번 실행 안에서만 한다 (연결 → 작업 → 끊기). «연결해 두고 대화하기» 는 하지 않는다

## 1단계 — 지금 상태 보기

```powershell
.\.venv\Scripts\python.exe -X utf8 evpn.py
```

| 줄 | ❌ 이면 |
|---|---|
| `AXGATE 클라이언트` | 2단계 (선생님이 직접 깐다) |
| `EVPN 아이디·비밀번호` | 3단계 |
| `EVPN 도우미` | 4단계 |

셋 다 «있음·설치됨» 이면 5단계로 바로 간다. `❌ 설정 파일이 없습니다` 가 나오면 원래 지시서의 설정 마법사부터 한다.

## 2단계 — AXGATE 설치 (선생님이 직접, 약 10분)

이건 네가 대신 못 한다 (포털 로그인·설치 파일 실행이 사람 몫이다). 아래를 **그대로** 안내하고, 끝나면 알려 달라고 해.

1. 크롬으로 https://evpn.sen.go.kr 에 들어간다
2. 주소창 아래 «이 기기의 다른 앱 및 서비스에 액세스» 가 뜨면 **[허용]**
3. 화면 가운데 «EVPN 프로그램 설치 관련 안내» 팝업은 아래쪽 **[닫기]**
4. 왼쪽 LOGIN 칸에 **EVPN 아이디·비밀번호** → **[LOGIN]**
5. 윗줄에 «설치 Yes» 가 보여도 **처음이면 [다운로드]부터** 누른다 (설치 안 됐는데도 Yes 로 보인다 — 실측)
6. 받은 파일(`UpdateAgent_…exe`)을 실행 → «AXGATE VPN Client» 설치 창이 **약 8분** 혼자 돈다 → **[Finish]**
   - «이 앱이 디바이스를 변경하도록 허용하시겠어요?» 가 뜨면 **[예]**
7. 포털 오른쪽 위 **[LOGOUT]** 으로 나온다

끝났다고 하시면 1단계를 다시 돌려 `AXGATE 클라이언트 설치됨` 을 확인한다.

## 3단계 — EVPN 아이디 저장

선생님께 **EVPN 아이디만** 여쭤봐 (비밀번호는 묻지 마). 그리고:

```powershell
.\.venv\Scripts\python.exe -X utf8 evpn.py setup --user <EVPN아이디>
```

- EVPN 비밀번호가 **인증서 암호와 같으면** 따로 넣을 게 없다 (이미 저장된 인증서 암호를 그대로 쓴다).
  같은지 선생님께 여쭤봐
- **다르면** 아래를 돌리고 «새 검은 창에 EVPN 비밀번호를 치고 Enter, 화면에 아무것도 안 보이는 게 정상» 이라고 안내해

  ```powershell
  .\.venv\Scripts\python.exe -X utf8 evpn.py password
  ```

- 마지막 줄이 `확인: 아이디 있음 · 비밀번호 있음` 이면 된 것이다

## 4단계 — 도우미 설치 ([예] 한 번)

**돌리기 전에 먼저 이렇게 말해 줘:**
«곧 화면에 "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜹니다. **[예]** 를 한 번 눌러 주세요.
처음 한 번만이고, 그다음부터는 연결할 때 아무것도 안 누르셔도 됩니다.»

```powershell
.\.venv\Scripts\python.exe -X utf8 evpn.py install
```

- 왜 필요한지 물으시면: EVPN 에 붙을 때 뜨는 «2차 인증» 창은 관리자 권한 프로그램의 창이라
  보통 권한으로는 글자를 넣을 수 없다. 그래서 관리자 권한 도우미를 **예약 작업**으로 한 번 등록해 둔다
- 바탕화면에 **«VPN 끊기»** 가 생긴다. «혹시 제가 멈춰 있고 인터넷이 안 되면 이걸 더블클릭하세요» 라고 알려 줘

## 5단계 — 한 번 붙여 보기 (약 1~2분)

업무포털이 열리는지만 보고 바로 끊는다. 아무것도 입력하지 않는다.

```powershell
.\.venv\Scripts\python.exe -X utf8 run_vpn.py --minutes 2 -- python -X utf8 -c "import urllib.request as u;print('업무포털 응답', u.urlopen('https://sen.eduptl.kr', timeout=20).status)"
```

- 도구의 timeout 은 **600000(10분)** 으로 준다
- 마지막 줄 `RESULT_JSON` 을 본다. `connected true · work_exit 0 · disconnected true` 이고
  그 위에 `업무포털 응답 200` 이 있으면 성공이다
- `connected false` 면 **한 번만** 다시 돌린다 (실측 10번 중 1번 실패, 바로 다시 하면 붙었다).
  두 번 다 안 되면 선생님께 크롬으로 evpn.sen.go.kr 에 직접 LOGIN 이 되는지 여쭤봐 (비밀번호 만료일 수 있다)

## 6단계 — 끝. 원래 지시서로 돌아간다

선생님께 이렇게 정리해 드려:
- 학교 밖 준비가 끝났다. 앞으로는 «연결 → 작업 → 끊기» 를 한 번에 한다
- 바탕화면 «VPN 끊기» 는 혹시 멈췄을 때만 쓴다

그리고 **네가 지킬 것:** 이제부터 나이스·업무포털·에듀파인에 들어가는 명령은 **전부** 이렇게 감싼다.

```powershell
.\.venv\Scripts\python.exe -X utf8 run_vpn.py -- python main.py 2026-09-14
.\.venv\Scripts\python.exe -X utf8 run_vpn.py --minutes 8 -- python edufine_inspect.py
```

- `--` 뒤는 원래 지시서에 적힌 명령에서 맨 앞 `.\.venv\Scripts\python.exe` 대신 `python` 이라고만 쓰면 된다
  (run_vpn 이 알아서 `.venv` 파이썬으로 바꾼다)
- 작업이 6분 30초를 넘을 것 같으면 `--minutes` 를 늘린다. 시간이 지나면 멈추고 끊는다
- 설정 마법사·`show_config.py`·`setup.ps1` 처럼 나이스에 안 들어가는 건 감쌀 필요 없다
