## A. 공동인증서 준비 (제일 먼저 확인)

이 도구는 **나이스에 인증서로 자동 로그인**합니다. 그래서 인증서가 이 PC에 있어야 합니다.

### A-1. 인증서가 PC에 있는지 확인

1. 브라우저에서 본인 지역 나이스에 접속합니다 (서울: `https://sen.neis.go.kr`)
2. **[인증서 로그인]** 버튼을 누릅니다
3. 인증서 목록 창이 뜨고 **내 이름이 보이면** 준비 끝입니다

목록이 비어 있다면 인증서가 이 PC에 없는 것입니다. 아래로 진행하세요.

### A-2. 인증서가 없다면 — 다른 PC/USB에서 옮기기

인증서는 보통 아래 폴더에 파일로 들어 있습니다.

```
C:\Users\<내계정>\AppData\LocalLow\NPKI\<발급기관>\USER\<인증서이름>
```

- 이 폴더를 통째로 복사해 **새 PC의 같은 경로**에 붙여넣으면 옮겨집니다
  (`signCert.der`, `signPri.key` 두 파일이 한 쌍입니다)
- USB로 옮겼다면 인증서 프로그램의 **[인증서 복사/가져오기]** 기능을 쓰는 게 더 안전합니다
- 인증서가 **아예 없거나 만료**됐다면 은행·행정전자서명(GPKI) 등 발급처에서 새로 받아야 합니다.
  **교육공무원은 학교 정보부에 문의하는 게 가장 빠릅니다.**

> 💡 인증서는 보통 **1년마다 만료**됩니다. 어느 날 갑자기 자동 로그인이 안 되면
> 만료를 먼저 의심해 보세요.

### A-3. ⭐ 인증서 "이름" 확인하기 (꼭 필요)

설정할 때 **인증서 이름을 정확히** 물어봅니다. 화면에 뜨는 그대로 적어야 합니다.

1. 나이스 → **[인증서 로그인]**
2. 뜬 목록에서 **내 인증서 줄에 적힌 글자를 그대로** 메모해 둡니다
   - 예시 형태: `홍길동`, `홍길동0012345`, `홍길동(교육부)` 등 발급기관마다 다릅니다
3. 이 값을 나중에 설정 마법사의 **"인증서 이름"** 에 넣습니다

> ⚠️ **전체를 다 적지 않아도 됩니다.** 도구는 목록에서 이 글자가 **포함된** 항목을 찾습니다.
> 다만 인증서가 여러 개면 헷갈릴 수 있으니 **가능한 한 그대로** 적으세요.
>
> 나중에 이름이 틀렸다는 걸 알게 되면 이것만 다시 바꿀 수 있습니다:
> ```powershell
> .\.venv\Scripts\python.exe fix_cert.py
> ```

### A-4. 비밀번호는 어디에 저장되나요

설정할 때 인증서 비밀번호를 한 번 물어봅니다. 이 값은 **파일로 저장되지 않고**
윈도우 **자격 증명 관리자**에 들어갑니다 (브라우저가 비밀번호를 기억하는 것과 같은 곳).

직접 확인/삭제하고 싶으면:
`시작 → "자격 증명 관리자" 검색 → Windows 자격 증명 → `neis-automation` 항목

## B. VS Code 설치

VS Code는 글자를 편집하는 프로그램입니다. Claude Code를 여기서 씁니다.

1. https://code.visualstudio.com/ 에서 **Download for Windows** 클릭
2. 받은 파일을 실행하고 계속 [다음] — **"PATH에 추가"는 체크된 채로** 두세요
3. 설치가 끝나면 VS Code를 실행합니다

### 처음 열면 아무것도 안 보입니다 — 정상입니다

VS Code는 **"폴더를 열어야"** 왼쪽에 파일 목록이 나옵니다.
지금은 열 폴더가 없으니 비어 있는 게 맞습니다. D단계에서 폴더를 만들고 열 겁니다.

### 터미널 여는 법 (자주 씁니다)

상단 메뉴 **[터미널] → [새 터미널]**, 또는 키보드 **Ctrl + `** (숫자 1 왼쪽의 물결 키).
화면 아래쪽에 검은 칸이 생기는데, 여기에 명령을 칩니다.

## C. Claude Code 설치

1. VS Code 왼쪽 세로 막대에서 **네모 4개 아이콘**(확장) 클릭
2. 검색창에 `Claude Code` 입력 → 설치
3. 설치 후 안내에 따라 로그인합니다 (Claude 계정이 필요합니다)

> Claude Code 없이 터미널 명령만으로도 다 쓸 수 있습니다.
> 다만 Claude Code가 있으면 **"9월 출결 넣어줘"** 처럼 말로 시킬 수 있어 훨씬 편합니다.

## D. 파이썬 설치

1. https://www.python.org/downloads/ 에서 **Download Python** 클릭 (3.10 이상)
2. 받은 파일을 실행합니다
3. ⭐ **설치 첫 화면 맨 아래 `Add python.exe to PATH` 를 반드시 체크하세요.**
   이걸 놓치면 나중에 `python은(는) 내부 또는 외부 명령이 아닙니다` 라는 빨간 글씨가 뜹니다.
4. **Install Now** 클릭
5. 설치 후 **VS Code를 껐다 켭니다** (안 그러면 방금 설치한 게 인식되지 않습니다)

확인: VS Code 터미널에서
```powershell
python --version
```
→ `Python 3.12.x` 처럼 나오면 됩니다.

> 체크를 놓치셨다면? 설치 파일을 다시 실행 → **Modify** → 다음 → `Add Python to environment variables` 체크 → Install.

## E. 이 저장소 내려받기

### git이 있는 경우

VS Code 터미널에서:
```powershell
cd $HOME
git clone https://github.com/workcalmkite-hue/neis-automation-kit.git
cd neis-automation-kit
code -r .
```

### git이 없는 경우 (더 쉬움)

1. 깃허브 저장소 페이지에서 초록색 **[Code] → [Download ZIP]**
2. 받은 zip을 **압축 풀기** (예: `C:\Users\내계정\neis-automation-kit`)
   - ⚠️ **바탕화면이나 다운로드 폴더보다는 사용자 폴더 바로 아래**가 안전합니다.
     경로에 공백이나 한글이 많으면 가끔 문제가 생깁니다.
3. VS Code에서 **[파일] → [폴더 열기]** → 방금 압축 푼 폴더 선택
4. 왼쪽에 파일 목록이 보이면 성공입니다

## F. 설치 스크립트 실행

VS Code 터미널에서:

```powershell
.\setup.ps1
```

파이썬 확인 → 가상환경 만들기 → 패키지 설치 → 크롬 제어 도구 설치까지 알아서 합니다.
**1~3분** 걸립니다. `설치 완료!` 가 나오면 됩니다.

> **`이 시스템에서 스크립트를 실행할 수 없으므로` 라는 빨간 글씨가 뜨면**
> 아래를 한 번 실행하고 다시 `.\setup.ps1` 하세요.
> ```powershell
> Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
> ```
