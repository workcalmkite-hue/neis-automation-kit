# 4. 문제 해결

> **빨간 글씨가 떴다고 처음부터 다시 깔지 마세요.** 거의 다 아래에 있습니다.
> Claude Code를 쓰신다면 **에러 문구를 통째로 복사해 붙여넣고 "이거 무슨 뜻이야"** 라고 물어보는 게 가장 빠릅니다.

---

## 설치 단계

| 증상 | 해결 |
|---|---|
| `python은(는) 내부 또는 외부 명령... 이 아닙니다` | 파이썬 설치 때 **Add python.exe to PATH** 를 안 눌렀습니다. 설치 파일 재실행 → Modify → `Add Python to environment variables` 체크 → VS Code 껐다 켜기 |
| `이 시스템에서 스크립트를 실행할 수 없으므로` | `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` 한 번 실행 후 다시 `.\setup.ps1` |
| `.\setup.ps1 : 용어를 인식할 수 없습니다` | 폴더 위치가 다릅니다. `pwd` 로 확인하고 `cd` 로 저장소 폴더로 이동 |
| `pip ... SSL` / 설치가 계속 실패 | 학교망 방화벽일 수 있습니다. 개인 인터넷(테더링 등)에서 설치만 한 번 돌려보세요 |
| 왼쪽에 파일 목록이 안 보인다 | VS Code에서 **[파일] → [폴더 열기]** 를 안 했습니다 |

---

## 설정 단계

| 증상 | 해결 |
|---|---|
| `설정 파일이 없습니다` | `python setup_wizard.py` 를 아직 안 돌렸습니다 |
| `oauth_client.json 파일이 없습니다` | [02번 문서 5단계](02_구글-연동.md) 참고. 파일명이 정확한지 확인 (`.json.txt` 로 저장되는 경우가 많습니다) |
| `액세스 차단됨: 앱이 Google 인증 절차를...` | 구글 클라우드 → OAuth 동의 화면 → **테스트 사용자**에 내 이메일 추가 |
| `Google에서 확인하지 않은 앱입니다` | **정상입니다.** [고급] → [(프로젝트 이름)(으)로 이동] |
| 설정을 잘못 넣었다 | `python setup_wizard.py` 를 다시 돌리면 됩니다. 기존 값이 기본값으로 나오니 바꿀 것만 고치세요 |
| 인증서 이름만 바꾸고 싶다 | `python fix_cert.py` |

## 실행 단계 — 로그인

| 증상 | 원인 | 해결 |
|---|---|---|
| 인증서 창은 뜨는데 자동 선택이 안 된다 | 설정의 **인증서 이름**이 실제와 다르다 | 나이스 인증서 목록에 뜨는 글자를 그대로 메모 → `python fix_cert.py` |
| `인증서 비밀번호를 찾을 수 없습니다` | 자격 증명 관리자에 저장이 안 됐다 | `python fix_cert.py` 로 다시 저장 |
| 비밀번호는 들어가는데 로그인이 안 된다 | 인증서 만료 | 나이스에 **수동으로** 로그인해보세요. 거기서도 안 되면 인증서 문제입니다 |
| 크롬이 안 열린다 / `channel="chrome"` 오류 | 구글 크롬이 이 PC에 없다 | 크롬을 설치하세요 (엣지·웨일로는 안 됩니다) |
| 학교 밖이라 나이스가 아예 안 열린다 | VPN 미연결 | 교육청 VPN을 **먼저 직접 연결한 뒤** 실행하세요. VPN 자동 연결은 이 키트에 없습니다 |

## 실행 단계 — 출결 입력

| 증상 | 원인 | 해결 |
|---|---|---|
| `해당 기간에 입력할 출결이 없습니다` | 캘린더 제목 형식이 틀렸거나, 다른 캘린더에 넣었다 | [03번 문서](03_캘린더-입력규칙.md)의 제목 형식 확인 |
| 어떤 학생만 빠졌다 | 그 일정만 제목 형식이 틀렸다 | `14번 김하늘` 처럼 "번"이 붙었는지 확인 |
| `알 수 없는 분류` | 캘린더 이름이 표와 다르다 | 캘린더 이름을 정확히 맞추거나 새로 만드세요 |
| `메뉴 이동 실패` 가 3번 뜨고 멈춘다 | 나이스 공지 팝업이 메뉴를 가렸다 | 열린 크롬에서 팝업을 닫고 다시 실행 |
| 중간에 멈추고 크롬이 열려 있다 | 나이스 화면 구조가 바뀌었을 수 있다 | 화면을 보고 어디서 멈췄는지 확인 → 이슈로 알려주세요 |
| 교시가 엉뚱하게 들어갔다 | 틸드 방향이 반대 | 조퇴 `5교시~` / 지각 `~2교시` — [03번 문서](03_캘린더-입력규칙.md) |

## 실행 단계 — 복무 신청

| 증상 | 해결 |
|---|---|
| `개인결재선 프리셋 이름이 없습니다` | 나이스에 결재선을 먼저 저장하고, 그 이름을 설정에 넣으세요 (`python setup_wizard.py`) |
| 결재선 목록에서 못 찾는다 | 나이스에 저장된 이름과 **글자가 정확히 같아야** 합니다 (쉼표·띄어쓰기 포함) |
| 일수가 `1일 2시간 30분` 으로 들어갔다 | 몇 시간짜리인데 나이스가 `1일`을 붙인 것입니다. **상신 전에 `1일`을 지우세요** |
| 연락처 칸이 깨진다 | 마스크 입력 칸이라 그렇습니다. 도구는 한 글자씩 넣도록 돼 있으니, 수동으로 고칠 때도 지우고 천천히 입력하세요 |

## MCP가 안 붙을 때

| 증상 | 해결 |
|---|---|
| `/mcp` 목록에 `나이스출결`이 없다 | **VS Code를 껐다 켜지 않은** 경우가 대부분입니다. MCP 목록은 시작할 때 한 번만 읽힙니다 |
| MCP 서버가 시작하다 죽는다 | `.venv`가 없습니다. `.\setup.ps1` 을 먼저 돌리세요 |
| `구글 계정이 연동되지 않았습니다` | `python setup_wizard.py` 를 아직 안 돌렸습니다 |
| 경로 때문에 안 뜬다 | `.mcp.json`의 `command`를 절대경로로 바꿔보세요. `./` 를 빼면 윈도우에서 못 찾습니다 |

자세한 것은 [05_MCP-연결.md](05_MCP-연결.md).
