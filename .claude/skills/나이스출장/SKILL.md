# 나이스 출장 신청

인증서 자동 로그인은 [[나이스복무]] 스킬의 **4절**과 동일하다. 먼저 로그인한 뒤
`복무 > 개인출장관리` 로 이동한다.

> 스크립트는 없다. **Playwright MCP로 직접 조작**한다.

---

## 입력 (개인출장관리 > 신청)

1. `신청(새 창 열기)` → **출장신청** 다이얼로그

2. **기간정보**: 시작일자 달력 아이콘 클릭 → 날짜 선택 (시작=종료로 자동 세팅) →
   종료일이 다르면 종료일자 달력 아이콘을 다시 클릭
   - **연속된 여러 날은 한 행으로 넣는다.** 시스템이 일수를 자동 계산한다
     (예: 9/3~9/4 두 평일 → "2일")
   - ⚠️ 날짜칸에 `fill()` 하면 마스크가 깨진다. **반드시 달력 아이콘**

3. **시각**: 기본값(예: 08:20~16:20)을 그대로 쓴다.
   사용자가 다른 시간을 말하지 않는 한 임의로 바꾸지 않는다

4. ⚠️ **당일 몇 시간짜리면 「일수」를 반드시 고친다.**
   같은 날 몇 시간뿐인데도 나이스가 **`1일 2시간 30분`** 처럼 "1일 + 시간"으로 계산해 넣는다.
   → **`1일`을 지우고 `2시간 30분`만 남긴다.**
   - 종일 출장은 `1일`이 맞다
   - **시간을 기본값에서 바꿨으면 일수 칸을 반드시 눈으로 확인**하고 그 값을 사용자에게 보고한다

5. **일반복 / 요일반복 체크박스**: "매주 화요일"처럼 **반복되는** 출장에만 쓴다.
   연속된 날짜 범위(9/3~9/4)에는 쓰지 않는다 — 시작~종료만 넣으면 된다

6. **출장종류** (필수, 커스텀 콤보): 보통 관내/관외로 나뉜다.
   **같은 시도교육청 안이면 관내, 밖이면 관외.** 애매하면 사용자에게 확인한다
   - `browser_select_option` 이 안 먹는다 → 클릭해서 열고 옵션을 찾아 클릭

7. **연락처**: 설정의 `contact`. 이 폼의 마스크는 `___-____-____`
   (근무상황신청의 `(___)____-____` 와 **다르다**)
   → `Ctrl+A` → `Delete` → 한 글자씩 천천히 입력

8. **출장지**: 기관명 (예: `○○대학교 발명교육인재개발센터`)

9. **출장목적**: 프로그램명 (예: `발명교육 직무연수`).
   정확한 명칭을 모르면 **지어내지 말고 사용자에게 확인**한다

10. `승인요청` → `기안문서상신` → `개인결재선` → 설정의 `approval_line` 프리셋 선택 → `지정`
    - 연수·출장·조퇴가 **서로 다른 프리셋**일 수 있다. 사용자에게 어느 것인지 확인한다

11. **위임결재자지정 팝업이 뜨면** — 원결재자로 보낼지 대결자로 보낼지는 **학교 관행에 따라 다르다.**
    사용자에게 확인하고, 한 번 정해지면 설정이나 메모에 남긴다

12. `상신` → 알림을 순서대로 `확인`
    ("최종 결재자 이외의 결재자는 검토로 변경합니다" → "상신하겠습니까?" → "상신을 완료하였습니다")

13. **검증**: 목록에서 `조회` → 해당 행의 기간·일수·출장지·결재상태를 `aria-label`로 읽어
    **사용자에게 그대로 보고한다**
