# 출결 캘린더 등록

`main.py`가 캘린더 이벤트를 **정규식으로** 파싱한다. 형식이 틀리면 그 학생은 통째로 누락된다.
사용자가 말한 그대로("26번 임하준 인정결석")를 제목에 넣지 말고 **반드시 아래로 변환**한다.

---

## 1. 캘린더 선택 — 분류는 캘린더 이름이 정한다

| 캘린더 이름 | 언제 |
|---|---|
| `질병결석` `질병지각` `질병조퇴` | 아파서 |
| `미인정결석` `미인정지각` `미인정조퇴` | 사유 없음 |
| `출석인정결석` `출석인정지각` `출석인정조퇴` | 현장체험학습·공결 등 |

캘린더 ID는 설정 파일에서 읽는다:

```python
import teacher_config
cal_id = teacher_config.load_config()["calendars"]["질병결석"]
```

> 다른 캘린더(개인 일정 등)에 넣으면 `main.py`가 읽지 않는다.

---

## 2. 제목 형식

```
{번호} {이름} {분류} (메모)
```

파서는 `/^(\d+)\s+(\S+)/` 로 매칭한다 → **번호 뒤에 "번"을 붙이면 안 되고,
숫자 바로 뒤에 공백**이 와야 한다.

| ⭕ | ❌ |
|---|---|
| `14 김하늘 질병결석` | `14번 김하늘 질병결석` |
| `22 이서준 질병결석 (생리결석)` | `김하늘 질병결석` (번호 없음) |
| `7 박지우 질병지각 (~2교시)` | `14김하늘 질병결석` (공백 없음) |

분류 글자는 파서가 읽지 않지만(캘린더 이름으로 판단), **사람이 읽기 위해 캘린더명과 똑같이** 적는다.

---

## 3. 교시 표기 — 틸드가 "빠진 구간"을 가리킨다

| 분류 | 표기 | 뜻 |
|---|---|---|
| **조퇴** | `5교시~` | 4교시까지 있다가 **5교시부터** 하교 |
| **지각** | `~2교시` | 1~2교시 결석, **3교시부터** 등교 |
| **결석** | (안 적음) | 하루 전체 |

사용자가 교시를 안 말했으면 **지어내지 말고 물어본다.**

---

## 4. 기간

- **조퇴·지각**: 항상 **하루**만
- **결석**: **종일(all-day) 이벤트**. 구글 캘린더는 종료일이 exclusive라
  "7/9~7/13 결석"이면 시작 `2026-07-09`, 종료 **`2026-07-14`**

주말은 `main.py`가 자동으로 건너뛴다.

---

## 5. 같은 날 두 건

지각 + 조퇴가 같이 있으면 **각각 해당 캘린더에 따로** 넣는다. 순서는 신경 쓰지 않아도 된다
— `main.py`가 빠진 시간 순으로 정렬해서 넣는다.

---

## 실행

구글 캘린더 MCP가 있으면 그걸 쓴다:
- `calendarId`: 분류에 맞는 캘린더 ID
- `summary`: 위 제목 형식
- `startTime` / `endTime`: 날짜만 (`YYYY-MM-DD`), `allDay: true`, `timeZone: "Asia/Seoul"`

MCP가 없으면 사용자에게 **캘린더 화면에서 직접 넣도록** 위 형식을 코드블럭으로 알려준다.

---

## 예시

사용자: *"26번 임하준 7월 9일부터 13일까지 인정결석이야"*

→ `출석인정결석` 캘린더에
`summary="26 임하준 출석인정결석"`, `start=2026-07-09`, `end=2026-07-14`, `allDay=true`

사용자: *"2번 김철수 오늘 2교시부터 조퇴했어, 아파서"*

→ `질병조퇴` 캘린더에 `summary="2 김철수 질병조퇴 (2교시~)"`, 오늘 하루

---

## 서류 챙기기 (선택)

**질병결석 · 출석인정결석 · 출석인정조퇴 · 출석인정지각** 4개는 서류를 받아야 한다.
할일 관리 도구(TickTick 등)가 연결돼 있으면 같은 자리에서 리마인더도 만든다.

- 제목: `{이름}에게 {분류} 서류 받기` (인정 계열은 `보고서 받기`)
- 마감: **마지막 결석일 + 1일**을 후보로 잡고, 주말이면 다음 평일로 미룬다
  - ⚠️ 마지막 날 자체를 마감일로 쓰지 않는다. 반드시 +1일부터 시작
  - 결석은 종일 이벤트라 `endTime`이 이미 "마지막 날 + 1"이다 → **그 값을 그대로 후보로** 쓰면 실수가 준다
- 미인정 계열 · 질병조퇴 · 질병지각은 대상이 아니다

## 개인정보 주의

학생 이름·번호·출결 사유는 **캘린더와 나이스에만** 둔다.
저장소 안에 명단 파일(`.csv`, `.xlsx`, `.md`)로 만들지 않는다.
