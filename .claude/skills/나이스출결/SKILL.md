# 나이스 출결 자동 입력

## 실행

저장소 폴더에서:

```powershell
$env:PYTHONUTF8='1'; .\.venv\Scripts\python.exe main.py
```

- 인자 없이 → **이번 달 1일부터 오늘까지**
- 특정 날짜부터 → `main.py 2026-09-10`
- 미래 날짜도 미리 넣기 → `main.py --future`
- **처음 쓰는 사용자면 `--dry-run` 을 먼저 권한다** — 목록만 보여주고 나이스를 열지 않는다

가상환경을 안 쓰면 `python main.py`.

## 실행 전에 확인할 것

1. **학교 안**인지 (또는 교육청 VPN이 연결돼 있는지) — 밖이면 나이스가 아예 안 열린다
2. 크롬이 이미 같은 프로필로 열려 있지 않은지
3. 캘린더 제목 형식이 맞는지 → [[출결등록]] 스킬

## 동작

크롬이 열리고 → 인증서 자동 로그인 → `학급담임 > 출결관리 > 출결관리` 이동 →
날짜별로 학생 입력 → 저장. **입력할 목록을 먼저 출력하므로 거기서 오타를 잡을 수 있다.**

- 분류는 **캘린더 이름**으로 판단한다 (제목의 분류 글자는 사람이 읽기 위한 것)
- 주말·휴업일은 자동으로 건너뛴다
- 같은 학생이 하루에 여러 건이면 **빠진 시간이 짧은 것부터** 넣고 가장 많이 빠진 건을 마지막에 넣는다
  (나이스가 마지막 입력을 최종 상태로 잡기 때문)
- **교시 열은 그날 시간표에 따라 개수가 달라진다.** 날짜를 조회한 뒤 헤더에서 컬럼명을 읽어
  `5교시` 처럼 **이름으로** 위치를 찾는다 (`read_day_columns` / `gyosi_col_index(n, day_cols)`).
  위치를 `3 + 교시번호`로 고정하면 3교시까지인 날 5교시를 요구할 때 **'사유' 칸을 눌러버린다** —
  오류도 안 나고 조용히 틀린 값이 들어간다 (2026-09-01에 실제로 겪은 문제)
- 그날 없는 교시를 요구하면 **그 학생은 아무것도 입력하지 않고 `⛔` 로 알린다.** 추측해서 넣지 않는다

## 끝난 뒤

**나이스 화면에서 눈으로 확인한다.** 사용자에게도 확인을 권한다.

캘린더와 나이스가 어긋난 곳을 찾으려면 (읽기 전용, 아무것도 안 고침):

```powershell
.\.venv\Scripts\python.exe verify_attendance.py 2026-09-01 2026-09-30
```

결과는 `verify_result.json` 으로 저장된다. **이 파일에는 학생 이름이 들어 있으니 커밋하지 않는다**
(`.gitignore`에 걸려 있다).

## 고칠 때 — 마감을 먼저 풀어야 한다

마감된 날은 **셀을 눌러도 팝업이 안 뜬다.** 순서는 **월마감 취소 → 일마감 취소**.

- **월**: `출결관리 3단계` → 탭 `반별월출결마감관리` → 조회 →
  **그리드에서 해당 월 행을 클릭**(이게 하단 폼을 채운다) → `취소`
  - 학기/월 콤보를 직접 건드리려 하지 말 것. 비활성이라 클릭이 안 된다 — **행 클릭이 정답**
  - `마감`/`취소` 버튼은 그리드 헤더의 '마감' 글자와 헷갈린다 → **'취소' 버튼과 같은 y좌표**에 있는 것을 고른다
- **일**: `일일출결관리(담임용)`에서 날짜 조회 → `마감취소`

### 수정

- **추가**: `main.py` 의 `enter_student(page, {...})` 재사용 → `save_page(page)`
- **삭제**: 그리드 좌측 상단 **`깨끗이` 체크박스를 켠 뒤 그 학생 마감 셀 클릭** → 행이 지워진다 → 저장
  - 팝업에는 삭제 항목이 없다. 라디오는 열 때 항상 전부 미선택으로 뜬다

### 재마감

일마감(`출결마감`) → 월마감(`반별월출결마감관리` → 해당 월 행 클릭 → `일` 입력 → `마감`).
학기 마지막 달은 **학기종료일**을 마감일자로 넣는다.

## 그리드를 읽을 때 (실측)

- **열 개수는 그날 시간표 교시 수에 따라 달라진다.** 열 위치를 고정하지 말고
  **헤더 행(`번호`로 시작)에서 컬럼명을 읽어** 매핑한다
- **데이터 행은 index 2에 빈 칸이 하나 더 있다** → 헤더 i번째 값 = 데이터 행의 `i<2 ? cells[i] : cells[i+1]`
