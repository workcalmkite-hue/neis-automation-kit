# 41조 연수 신청

인증서 자동 로그인은 [[나이스복무]] 스킬 **4절**과 동일. 화면은 `복무 > 개인근무상황관리`.

- 사유·목적지는 **학교 공지의 고정 서식**을 따른다 (예: 사유 `수업연구 및 자율연수` / 목적지 `자택 등`).
  공지를 못 봤으면 **지어내지 말고 사용자에게 확인**한다
- 결재선은 41조 전용 프리셋이 따로 있는 경우가 많다 (조퇴·출장 프리셋과 **다르다**).
  어느 것인지 사용자에게 확인한다

---

## 1. 기간 계산 (필수, 절대 추측 금지)

1. 학교 공지에서 **41조 연수 전체 기간**을 확인한다
   (보통 "방학식 다음날 ~ 개학 전날"). 마지막 날이 대체공휴일 등으로 근무일이 아니면 그 앞날까지
2. 그 기간 안에 이미 잡혀 있는 **모든 출장·연수·근무상황 일정**을 확인한다
   (`개인출장관리` / `개인근무상황관리` 조회, 또는 사용자에게 확인)
   → **시간대와 무관하게 겹치는 날은 전부 제외한다** (저녁 시간대 출장도 포함)
3. **모든 시작·종료일의 요일을 코드로 검증한다.** 직접 계산하지 않는다
4. 제외 날짜를 뺀 **연속 구간들로 분할**해 표로 만들어 **사용자에게 확인받은 뒤** 입력한다
   - 애매한 점(예: 마지막 구간이 왜 짧은지)은 추측하지 말고 질문한다

---

## 2. 입력 (구간마다 반복)

1. `복무 > 개인근무상황관리` → 상단 `신청` → 근무상황신청 다이얼로그
2. `근무상황대분류` 콤보 → **`연수`**
   - 커스텀 콤보라 `select_option` 이 안 먹는다. 클릭해서 열고 옵션을 클릭.
     **첫 클릭에 드롭다운이 안 열리는 경우가 있으니** 열렸는지 확인하고 필요하면 재클릭
3. `근무상황소분류`는 연수 선택 시 **`교육공무원법제41조연수`로 자동**으로 채워진다 (조작 불필요)
4. 시작일자 달력 아이콘 → 시작일 클릭 (시작=종료 자동 세팅).
   종료일이 다른 달이면 `다음달` 버튼으로 이동
   - ⚠️ 날짜칸에 `fill()` 하면 마스크가 깨진다 (`7-22-월-일` 처럼 들어감). **반드시 달력**
5. 구간이 여러 날이면 종료일자 달력 아이콘을 다시 클릭해 종료일 선택
   - **주말은 시스템이 자동으로 뺀다.** 요일반복 체크 불필요 — 계산된 일수만 확인
6. `연락처`: 마스크 칸 → `Ctrl+A` → `Delete` → 한 글자씩 천천히 입력
7. `사유 또는 용무` / `목적지` 입력
8. `승인요청` → `기안문서상신` → `개인결재선` → 41조용 프리셋 → `지정`
9. `상신` → 알림을 순서대로 `확인`
10. 다음 구간 반복

---

## 3. 주의사항

- **상신 전에** `기안내용` 그리드에서 연락처·기간·사유를 한 번 더 확인한다
- 승인요청 후 빠뜨린 걸 알아챘다면, 기안문서상신 화면에서 `취소` → 근무상황신청이
  **임시저장 상태로 목록에 남는다** (데이터 유실 없음).
  목록에서 해당 행의 `기간` 링크를 클릭하면 수정 화면으로 다시 들어간다
- 구간을 여러 개 넣을 때는 **각 구간이 상신됐는지 목록에서 확인**한 뒤 다음으로 넘어간다
